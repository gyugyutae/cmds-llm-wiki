# 국내 개발·AI 공모전 8개 비교와 포트폴리오 적합도

## 빅콘테스트는 할 만한가?

**참가해서 경험을 쌓는 건 해볼 만하지만, 수상은 쉽다고 보면 안 된다.** 기업 데이터를 분석하고 모델 결과뿐 아니라 문제 해석과 실효성까지 설득해야 하므로, 데이터 분석을 처음 하는 팀이 상을 전제로 일정 전체를 걸기에는 불확실성이 크다. 공식 공고가 밝힌 접수 기간은 10월 26일까지라 준비 시간은 있지만, 실제 참가 페이지에서 제출 형식과 마감 시각을 다시 확인해야 한다.

수상을 못 해도 코드, 기준선 모델, 데이터 분할·평가 방식, 오류 분석, 문제에서 도출한 인사이트를 정리하면 데이터 프로젝트로 활용할 수 있다. 다만 사용 데이터의 공개 가능 범위와 대회 규정은 따라야 한다. “빅콘테스트 참가”와 “수상”을 이력서에 구분하고, 상을 받지 않았으면 구현·분석한 프로젝트를 사실대로 적는다.

## 추천 순서

1. **개발 포트폴리오를 우선하면: 고용24** — 2인 팀이 가능하고 기능 구현과 시연이 명확하다.
2. **지역에서 바로 실전 개발을 해보고 싶으면: 경남 AI·SW** — GNU 재학생에게 잘 맞지만 9월 29일 정오 마감이라 즉시 결정해야 한다.
3. **사회문제 서비스를 끝까지 만들어보고 싶으면: 사회문제 해결 챌린지** — 9월 30일까지 서비스 개발 트랙으로 신청한다.
4. **AI 에이전트 코드 실험을 원하면: N.O.V.A.** — 건강 도메인과 Python 기반 평가가 맞을 때 선택한다.
5. **데이터·ML을 원하면: KISTI 또는 빅콘테스트** — KISTI는 문제별 데이터 모델, 빅콘테스트는 기업 데이터 분석·인사이트에 더 가깝다.
6. **기획 발표 중심이면: K-DATA 데이터 문제해결 또는 핀테크** — 코드·배포 포트폴리오가 목표라면 앞 순위 대회보다 우선하지 않는다.

여러 대회에 지원서를 내는 것보다 한 대회에서 역할을 나누고 완성 가능한 결과물을 남기는 편이 낫다. 일정이 겹치므로 경남 대회 단기 스프린트와 10~11월 장기 개발 대회를 동시에 진행할 수 있는지 팀 시간을 먼저 확인한다.

## 수상하지 않아도 남길 포트폴리오 증거

- 문제 정의와 대상 사용자, 입력·출력·제약을 한 페이지로 정리한다.
- GitHub에 본인 구현 범위, 역할 분담, PR·이슈 기록, 실행 방법을 남긴다.
- 데이터 대회라면 기준선, 평가 지표, 분할 방식, 실패 사례와 해석을 기록한다.
- 서비스 대회라면 API·데이터 흐름도, 테스트, 배포 링크 또는 짧은 시연 영상을 남긴다.
- 사용한 데이터·AI 도구·외부 라이브러리와 라이선스, 대회 규정을 확인한다.
- 결과는 `참가`, `본선 진출`, `수상`, `직접 구현`을 구분해 이력서에 쓴다.

> [!note] Bias Check
> 우선순위는 두 명의 소프트웨어공학 학생이 수상 여부와 무관하게 개발 포트폴리오를 남기려는 목적에 맞춘 판단이다. 팀의 현재 ML 경험, 주당 투입 시간, 세부 과제 적합도는 확인되지 않았다. 일정은 2026-09-28 기준으로 확인했으며 대회 운영에 따라 바뀔 수 있다. 빅콘테스트와 핀테크의 일부 세부 정보는 공식 동적 페이지 외에 공개 공모전 안내도 대조했으므로 신청 직전 공식 페이지에서 접수·제출 기한과 참가 규정을 다시 확인한다. 승률이나 수상 확률은 추정하지 않았다.
