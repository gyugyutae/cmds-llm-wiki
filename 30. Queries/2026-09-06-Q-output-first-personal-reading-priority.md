# Output-first 개인 독서 우선순위

## 결론

현재 가장 필요한 책은 더 많은 성공·AI 전망서가 아니라 `직접 구현을 시작하게 하는 기술서 1권`, `조급함을 낮춰 선택을 돕는 책 1권`, `성과와 인간 가치를 분리해 보는 소설 1권`이다.

첫 8주 핵심 큐는 다음과 같다.

1. 이미 보유한 《스프링 부트와 AWS로 혼자 구현하는 웹 서비스》
2. 《4000주》
3. 《프로그래머의 뇌》
4. 《앨저넌에게 꽃을》
5. 《남아 있는 나날》
6. 《객체지향의 사실과 오해》

동시에 펼쳐두는 책은 최대 3권으로 제한한다: 기술서 1권, 논픽션 1권, 소설 1권.

## 확인된 사실

- Core Context상 현재 사용자는 소프트웨어공학과 4학년이며 금융권·핀테크 Java 백엔드를 1차 목표로 둔다.
- 현재 가장 큰 취업 증거 공백은 Java·SQL로 직접 구현하고 수정·검증한 기록이다.
- 사용자는 독서 내용을 코드와 일상에 적용하고 블로그에 기록하는 것을 성장으로 보며, input보다 output을 늘리고 싶다고 했다.
- 사용자는 이동욱의 《스프링 부트와 AWS로 혼자 구현하는 웹 서비스》를 이미 보유하고 있다.
- 이미지에서 결제 선택된 장바구니는 8종 13권, 결제 예정 금액 253,180원이다. 《인간의 굴레에서 1》 3권, 스프링 책 2권, 정보처리기사 실기책 2권, 《종의 기원담》 2권이 담겨 있다.

## 장바구니 조정

개인 소장용이라는 전제에서 지금 결제할 최소 묶음은 다음 네 권이다.

1. 《앨저넌에게 꽃을》 1권
2. 《남아 있는 나날》 1권
3. 《4000주》는 종이책 재고가 없으면 eBook·도서관·타 서점을 이용

다음 주문 또는 도서관 후보는 《프로그래머의 뇌》와 《객체지향의 사실과 오해》다.

- 《인간의 굴레에서 1》은 3권이 아니라 1권만 필요하다. 완독하려면 1부를 여러 권 사는 대신 1·2권 각 1권이 필요하다. 긴 소설이므로 첫 큐 뒤로 미룬다.
- 이미 보유한 스프링 책을 먼저 사용하므로 《스프링 부트 4 개발자 되기 + AI》는 지금 추가 구매하지 않는다. 정보처리기사 실기책과 《종의 기원담》도 개인용이면 각 1권으로 줄인다.
- 정보처리기사 실기책은 필기 합격 또는 실기 시험이 6~8주 안에 있을 때만 구매한다. 자격증이 프로젝트 시간을 밀어내면 우선순위가 뒤집힌다.
- 《스토너》는 좋은 선택이지만 《남아 있는 나날》과 주제가 겹친다. 지금은 후자를 먼저 읽고 《스토너》는 다음 소설로 둔다.
- 여러 권 수량이 동아리·선물용이라면 수량 조정 판단은 적용하지 않는다.

## 전체 우선순위

### S — 지금 읽고 바로 적용

1. **이미 보유한 《스프링 부트와 AWS로 혼자 구현하는 웹 서비스》**
	- 이유: Java 금융 백엔드라는 현재 목표와 직접 연결되고, JPA·테스트·인증·배포의 전체 흐름을 한 번 경험할 수 있다. 새 책을 사는 것보다 보유한 책에서 output을 만드는 편이 우선이다.
	- 주의: 2019년 책으로 Spring Boot 2.1, Gradle 4, 당시 AWS·OAuth 환경을 기준으로 한다. 새 프로젝트는 지원 중인 안정 버전으로 생성하고 책은 구조와 순서의 안내서로 사용한다. 버전 차이는 공식 문서로 확인해 마이그레이션 로그로 남긴다.
	- 추가 구매 기준: CRUD·JUnit·JPA까지 진행했는데 두 주 연속 학습시간의 30% 이상이 버전 오류 해결에 쓰이거나, 최신 Security·CI/CD를 스스로 옮기지 못할 때만 《스프링 부트 4 개발자 되기 + AI》를 도서관에서 먼저 확인한 뒤 구매한다.
	- output: 장마다 금융 주문 프로젝트 커밋 1개, 실패 테스트 1개, `왜 이렇게 설계했는가` 200~500자.
	- 외부 확인: https://freelec.co.kr/book/%EC%8A%A4%ED%94%84%EB%A7%81-%EB%B6%80%ED%8A%B8%EC%99%80-aws%EB%A1%9C-%ED%98%BC%EC%9E%90-%EA%B5%AC%ED%98%84%ED%95%98%EB%8A%94-%EC%9B%B9-%EC%84%9C%EB%B9%84%EC%8A%A4/

2. **《4000주》**
	- 이유: 연애, 취업, 서울 생활을 모두 빨리 얻어야 한다는 조급함과 생산성 집착을 직접 다룬다. 효율성의 함정, 미래 통제, 휴식, 외로움이 현재 고민과 맞닿아 있다.
	- output: 더 할 일 목록을 늘리지 말고 `이번 8주에 포기할 것 3개`와 `그 자체가 목적인 시간 1개`를 정한다.
	- 외부 확인: https://www.yes24.com/product/goods/107027241

3. **《프로그래머의 뇌》**
	- 이유: 코드를 읽고 기억하고 이해하는 과정을 인지과학으로 설명하므로, Java와 낯선 코드베이스를 공부하는 방법을 바꾸는 데 유용하다.
	- output: 매주 이해하기 어려웠던 코드 한 조각을 골라 생소한 문법, 도메인 지식, 흐름 문제 중 어디서 막혔는지 분류한다.

4. **《앨저넌에게 꽃을》**
	- 이유: 지능과 성취가 올라가면 인간의 가치와 관계도 자동으로 좋아지는지 묻는다. 실력·직장·돈·연애를 자기 가치 하나로 묶는 경향을 보완한다.
	- output: 생산성 교훈을 억지로 뽑지 않는다. `내가 능력으로 사람을 평가한 장면` 하나만 기록한다.

5. **《남아 있는 나날》**
	- 이유: 직업적 위대함을 좇느라 감정과 관계를 억누른 사람이 뒤늦게 자신의 삶을 돌아본다. 개발자 성공과 워라밸, 사랑을 모두 고민하는 현재에 가장 날카로운 소설이다.
	- output: `좋은 직업인이 되기 위해 지킬 것`과 `직업 때문에 포기하지 않을 것`을 각각 3개 쓴다.
	- 외부 확인: https://www.yes24.com/product/goods/103168353

6. **《객체지향의 사실과 오해》**
	- 이유: 프레임워크 사용법보다 역할·책임·협력과 도메인 모델을 생각하게 한다. 새 금융 주문 프로젝트의 직접 설계 증거와 연결하기 좋다.
	- output: 읽은 개념으로 `Order`, `Account`, `Execution` 책임을 다시 나누고 before/after 이유를 ADR 한 장으로 남긴다.

### A — 첫 프로젝트 v1과 함께 읽기

- **《자바의 정석》**: 완독 대상이 아니라 진단에서 막힌 문법·컬렉션·예외·제네릭을 찾아 쓰는 기준서다.
- **《이펙티브 자바》**: Java 기본 코드를 직접 써본 다음 읽는다. 지금 먼저 읽으면 원칙 암기와 실제 판단이 분리될 수 있다.
- **《실용주의 프로그래머》**: 한 프로젝트에서 실제 실패와 수정 경험이 생긴 뒤 읽으면 자신의 사례와 연결된다.
- **《스토너》**: 일의 의미를 성취와 명성에서 분리해 보는 두 번째 직업 소설이다.
- **《모순》**: 안정과 도전, 사랑과 현실처럼 정답이 하나가 아닌 선택을 보는 데 유용하다.
- **《비폭력대화》**: 연애 기술보다 관찰·감정·욕구·요청을 구분하는 연습에 쓴다. 관계뿐 아니라 팀 리딩과 면접 피드백에도 적용한다.
- **《디자인 유어 라이프》**: 추가 추천. 금융 개발자·공기업·제3의 경로를 각각 5년 계획으로 그리고, 현직자 대화와 작은 프로젝트로 시험한다. 진로는 독서로 결론 내기보다 프로토타입으로 정보를 얻는다. 공식 Odyssey 방식: https://designingyour.life/insights/the-magic-of-odysseys-prototyping-your-future-with-designing-your-life/
- **《열정은 쓰레기다》(So Good They Can't Ignore You)**: 추가 추천. 좋아하는 일을 찾는 문제를 희소하고 가치 있는 역량을 축적하는 문제로 바꿔 본다. 개발을 실제로 경험하기 전에 적성을 결론 내리지 않게 돕는다. 저자 설명: https://calnewport.com/my-new-book-and-a-chance-to-speak-with-me-one-on-one/

### B — 목적이 생길 때 읽기

- **《구글 엔지니어는 이렇게 일한다》**: 문화·프로세스·도구를 다루는 큰 조직의 책이다. 개인 프로젝트 v1 이후 코드리뷰, 테스트, 문서화 장을 선별해서 읽는다. 지금 완독하면 관찰자 지식이 늘 가능성이 크다. 출판사 소개: https://www.hanbit.co.kr/store/books/look.php?p_code=B1207366943
- **《소프트 스킬》, 《린치핀》, 《성공하는 사람들의 7가지 습관》**: 모두 넓은 자기계발서다. 한꺼번에 읽지 말고 현재 행동 문제에 맞는 한 권만 고른다.
- **《아주 작은 습관의 힘》**: 독서를 더 하는 용도가 아니라 주 12시간 Java·SQL 루틴이 무너질 때 시스템을 고치는 용도로 쓴다.
- **《인간의 굴레에서》**: 짝사랑의 집착, 진로 방황, 성장이라는 현재 고민과 매우 잘 맞지만 길다. 첫 8주 프로젝트 리듬이 잡힌 뒤 읽는다.
- **《당신 인생의 이야기》, 《종의 기원담》**: AI 전망서와 달리 언어·지능·인간성 문제를 서사로 생각하게 한다. 둘 중 한 권부터 읽는다. 현재는 《앨저넌에게 꽃을》 다음이다.
- **《면도날》, 《데미안》, 《연금술사》**: 자기 길을 찾는 성장 서사가 겹친다. 셋 중 《면도날》 한 권을 먼저 고른다.
- **《브람스를 좋아하세요...》, 체호프 단편선**: 관계의 외로움과 어긋남을 보고 싶을 때 읽는다. 현재 그리움이 조금 가라앉은 뒤가 낫다.
- **《투자에 대한 생각》**: 투자 책 중에는 우선순위가 높다. 시장 주기와 위험을 생각하는 보완재로 읽되, 독서가 2배 레버리지나 대출 활용의 안전성을 증명하지는 않는다.
- **《생각에 관한 생각》**: 판단 편향을 다루는 고전이지만 `메타인지 실천서` 하나로 보기에는 범위가 다르고 매우 길다. 먼저 코딩 학습에는 《프로그래머의 뇌》, 학습법에는 《메이크 잇 스틱》을 선택한다.
- **《코스모스》, 《숨결이 바람이 될 때》, 《소유냐 존재냐》, 《자유론》**: 취업 효율과 무관하게 세계관을 넓히는 장기 독서로 남긴다.

### C — 지금은 미루기

- **《인간 실격》, 《불안의 서》, 《이방인》**: 중요한 문학이지만 현재의 거절감과 반추를 위로하기보다 고립과 자기혐오를 증폭시킬 수 있다. 상태가 안정됐을 때 읽는다.
- **AI 전망서 묶음**: 《넥서스》, 《라이프 3.0》, 《AI 2041》, 《수퍼인텔리전스》, 《딥 유토피아》를 연속해서 읽지 않는다. 현재 병목은 AI 미래 지식이 아니라 Java 직접 구현이다. 한 권만 고른다면 기업·권력·경쟁까지 보는 《슈프리머시》를 택한다.
- **부·성공 묶음**: 《세이노의 가르침》, 나발 라비칸트 책, 《주권 개인》, 《린치핀》을 연속해서 읽지 않는다. 개인의 의지·부·희소성·시장가치라는 같은 관점을 강화한다.
- **《실리콘밸리가 원하는 사람》**: 서울·실리콘밸리 선망을 강화할 수 있으므로 현직자 인터뷰와 실제 채용 공고보다 먼저 읽지 않는다.
- **《구글 엔지니어는 이렇게 일한다》와 토스 기술 블로그**: 둘 다 읽기보다 당장 자신의 저장소에 issue, PR 설명, 테스트, 장애 기록을 한 번 적용하는 것이 우선이다.

## 편향 진단과 추가 책

현재 목록은 남성 저자, 성공한 개인, 부와 레버리지, 실리콘밸리, AI 미래에 강하게 기울어 있다. 이 관점은 동기가 되지만 구조·돌봄·협력·평범한 삶·다른 성별의 경험을 놓칠 수 있다.

1. **《워킹 데드 해방일지》 — 시몬 스톨조프**
	- 추가 이유: `좋은 직업=좋은 삶`이라는 결합을 비판한다. 개발자와 공기업 선택에서 직업 밖의 정체성과 생활을 함께 보게 한다.
	- 확인: https://m.yes24.com/goods/detail/122545426

2. **《올 어바웃 러브》 — 벨 훅스**

## 후속 문학 선택 안내

- 사용자가 기억한 민음사 추천작은 프랑수아즈 사강의 《브람스를 좋아하세요…》일 가능성이 매우 높다. 폴·로제·시몽 세 사람의 삼각관계와 로제의 반복적인 외도를 다루지만, 단순한 불륜극보다 외로움·권태·자기기만을 보는 심리소설이다. 현재 관계 상처와 소재가 너무 가까우므로 즉각적인 위안보다 감정 반추를 일으킬 수 있어 첫 책보다는 뒤로 둔다.
- 《앨저넌에게 꽃을》은 지능 향상 수술을 받은 찰리의 기록을 통해 능력·존엄·사랑·고독을 묻는다. 세 권 중 가장 잘 읽히고 현재의 AI·성취 중심 관점을 보완하므로 먼저 읽는다.
- 《남아 있는 나날》은 직업적 품위와 충성을 우선해 감정·사랑·윤리적 판단을 미뤄 온 집사가 과거를 회상하는 소설이다. 개발자 성공과 워라밸 사이의 비협상 조건을 생각할 때 두 번째로 읽는다.
- 《종의 기원담》은 인간이 사라진 뒤 로봇 문명에서 로봇 케이가 생명과 종의 기원을 탐구하는 김보영의 연작 SF다. AI 전망을 더 읽는 대신 인간·비인간·창조·진화를 낯선 관점에서 생각하고 싶을 때 세 번째로 읽는다.

## 독서 output 규칙

- 기술서: 한 장을 읽으면 `코드 변경 + 테스트 + 판단 기록` 중 최소 2개가 있어야 다음 장으로 간다.
- 자기계발서: 한 권당 행동 실험 1개만 정하고 7일 뒤 결과를 쓴다.
- 문학: 모든 작품을 자기계발 재료로 만들지 않는다. 장면 하나와 자신의 반응 하나면 충분하다.
- 블로그: 매일 장문의 글을 쓰지 않는다. 주간 1회, `문제 → 시도 → 실패 → 수정 → 증거` 형식으로 프로젝트 기록을 합친다.
- 한 권을 시작하려면 기존 진행 책을 끝내거나 중단 이유를 기록한다. 구매 권수보다 커밋·테스트·독서 실험 수를 센다.
