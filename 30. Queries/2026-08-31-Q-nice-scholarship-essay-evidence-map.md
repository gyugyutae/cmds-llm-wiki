# NICE그룹 장학금 자기소개서 증거 지도

## 목표와 평가 구조

NICE 자기소개서는 진솔성, 논리성, 성실성, 성장 가능성, 목적 부합성을 각 20점으로 평가한다. 다섯 기준은 문항별 배점이라기보다 자기소개서 전체에 적용되는 평가 축으로 해석한다. 모든 문항에 모든 기준을 억지로 반복하지 않고, 전체 답변에서 각 기준에 복수의 사실 근거가 나타나게 설계한다.

## 권장 진로 문장

현재 확인된 금융권 관심과 최근 빅데이터 분석 관심을 연결해 `금융 데이터를 분석하여 고객·시장·시스템 의사결정을 개선하는 금융 데이터 분석가`로 확정하는 것이 가장 적합하다. `빅데이터 분석가`는 범위가 넓고, `퀀트 트레이더`는 현재 통계·확률·금융모형·백테스트 증거가 부족하며 NICE 데이터 애널리스트 교육과의 직접성이 낮다. 퀀트는 장기 확장 관심으로 두고, 2027년 1학기 Upbit 공개데이터 가설 검증·백테스트 프로젝트를 금융 데이터 분석가 진로의 첫 결과물로 배치한다.

## 사업목적 정합성 점검

현재 소재를 그대로 배열하면 `AI 도구와 자동화를 좋아하는 개발자`로 읽힐 위험이 있다. LLM Wiki와 Gemini Gem은 데이터 분석 경험이 아니라 지속 학습법으로 문항 1에만 사용하고, 중심 전환문을 다음처럼 둔다.

> AI로 시스템을 만드는 과정에서, 결과의 차이를 설명하고 다음 행동을 정하는 것은 도구 자체가 아니라 데이터라는 사실을 배웠다. Threads 반응지표를 분석한 경험을 계기로 금융 데이터 분석가라는 진로를 구체화했다.

사업목적과 신청자격을 뒷받침하는 구조는 `기존 행동 증거 → 기술 기반 → 진로 선언 → NICE 교육을 통한 성장 결과`다.

- 기존 행동 증거: Threads 게시물 지표를 형식·주제·실험군별로 비교하고 다음 생성에 반영
- 기술 기반: 소프트웨어공학, 데이터베이스 A0, Python/CSV 처리, Elasticsearch 연구 참여
- 진로 선언: 금융 데이터를 분석해 고객·시장·시스템 의사결정을 개선하는 금융 데이터 분석가
- 성장 결과: NICE 교육, SQLD·ADsP 학습, Threads 분석 포트폴리오, Upbit 공개데이터 금융 가설 검증 프로젝트

52행 Threads 자료를 `빅데이터`라고 부르지는 않는다. 이는 데이터 기반 의사결정의 초기 실전 경험이며, NICE 교육으로 분석 기획·통계·시각화 역량을 보완해 더 큰 금융 데이터로 확장한다고 쓴다.

## 문항 1의 LLM Wiki 배치

LLM Wiki는 `나를 나보다 더 잘 아는 AI`를 전면에 내세우기보다 `호기심을 일회성 소비로 끝내지 않는 축적 습관`으로 설명한다. 영상·글·문서를 관심 이유와 함께 기록하고, Wiki link와 Graph View로 서로 다른 분야의 반복 관심과 숨은 연결을 발견하며, 새 질문의 출발점으로 재사용하는 과정이 핵심이다. 이는 데이터 분석 경력의 증거가 아니라 성실성과 장기 성장 가능성의 증거다.

## 품질 경계

- 경쟁사 분석 이미지는 실제 발표자료의 비교축과 CUEE의 포지셔닝을 확인하지만, 비교 대상 서비스에 대한 독립 조사나 성능 우위를 증명하지는 않는다.
- U300+ 화면은 프로그램 일정, 팀당 멘토링 3회, 온라인 전시관, 네트워킹 데이, 최종 40팀 선발 구조를 확인한다. 김규태의 실제 참여·제출과 전국 400팀 선정은 사용자 자기보고로 구분한다.
- Threads 분석은 현재 `기초 참여지표 분석`으로는 충분하지만 고급 통계·빅데이터 분석으로 표현하지 않는다.
- [[Graduation-elasticsearch]]와 [[financial-order-latency-lab]]의 코드는 AI가 작성했거나 사용자가 직접 검증하지 않은 범위가 있으므로 개발·분석 성과로 과장하지 않는다.
- LLM Wiki 관련 인물은 CMDSPACE의 `구요한`이다. 웹에서는 티타임즈TV의 구요한 대표 옵시디언·생성형 AI 강연은 확인됐지만 사용자가 말한 KIST 공식 채널 영상은 확인하지 못했다. 자기소개서에는 채널 소속을 굳이 쓰지 않고 `구요한 대표의 강연`으로만 표현하는 편이 안전하다.
