# NICE그룹 장학금 자기소개서 증거 지도

## 목표와 평가 구조

NICE 자기소개서는 진솔성, 논리성, 성실성, 성장 가능성, 목적 부합성을 각 20점으로 평가한다. 다섯 기준은 문항별 배점이라기보다 자기소개서 전체에 적용되는 평가 축으로 해석한다. 모든 문항에 모든 기준을 억지로 반복하지 않고, 전체 답변에서 각 기준에 복수의 사실 근거가 나타나게 설계한다.

## 권장 진로 문장

현재 확인된 금융권 관심과 최근 빅데이터 분석 관심을 연결해 `금융 데이터를 분석하여 고객·시장·시스템 의사결정을 개선하는 금융 데이터 분석가`로 확정하는 것이 가장 적합하다. `빅데이터 분석가`는 범위가 넓고, `퀀트 트레이더`는 현재 통계·확률·금융모형·백테스트 증거가 부족하며 NICE 데이터 애널리스트 교육과의 직접성이 낮다. 퀀트는 장기 확장 관심으로 두고, 2027년 1학기 Upbit 공개데이터 가설 검증·백테스트 프로젝트를 금융 데이터 분석가 진로의 첫 결과물로 배치한다.

## 평가축별 20점 전략

- 진솔성: 데이터 분석 관심이 최근 생겼다는 시점을 숨기지 않고, 자격증이 없으며 프로젝트 코드의 AI 기여가 크다는 경계를 지킨다.
- 논리성: 금융 관심 → 소프트웨어공학 → 지표를 활용한 Threads 개선 → 금융 데이터 분석가 → NICE 교육과 프로젝트의 단일 인과선으로 연결한다.
- 성실성: 22학점 이수와 직전학기 4.1, 2026-05-25 이후 매일 게시, 연구·동아리 역할을 기간과 행동으로 제시한다.
- 성장 가능성: AI 답을 따라 하는 학습에서 질문을 연쇄적으로 파고드는 학습으로 바뀐 과정, 자격증이 없는 현재 수준에서 NICE 실무 데이터 분석까지의 간극을 구체적인 결과물로 메운다.
- 목적 부합성: 데이터 애널리스트 교육과정의 Python·Pandas·실무 데이터 분석을 현재 경험의 정확한 다음 단계로 배치한다.

## 확인된 Threads 데이터 증거

- 공개 저장소: https://github.com/gyutaetae/threads-agentic-editor-workflow
- CSV 열: 날짜, 형식, 콘텐츠축, 목표, 주제, hook, source, 실험군, 모델, 조회수, 좋아요, 답글, 재게시, 인용, 저장, 프로필 방문, 팔로우 증가 등 32개
- 로컬 CSV: 52행, 날짜가 있는 행 51개, 고유 날짜 45개, 2026-06-23~08-27
- 조회수가 있는 51행: 총 조회수 131,868회, 중앙값 1,147회, 평균 2,585.6회
- `tiny_source_case` 13개: 중앙 조회수 4,033회
- `research_checklist` 20개: 중앙 조회수 280.5회
- 코드의 `metrics_feedback()`은 최근 데이터의 audience replies, reposts, quotes, follows, saves, profile visits를 형식·콘텐츠축·게시시간·실험군별로 집계하고, 반응이 없으면 likes를 보조지표로 사용하여 다음 생성 지침에 넣는다.
- 저장소 자체도 지표를 `weak signal`로 사용하고 조회수·좋아요만 최적화하지 말라고 명시한다.
- 사용자 자기보고 운영 시작일은 2026-05-25이고 현재 팔로워는 650명이지만, CSV는 6월 23일부터라 전체 매일 게시 이력을 증명하지는 않는다.

## 확인된 SEALAB 연구 증거

- 연구 노트 제목: `A GraphDatabase–Based Approach to Measuring Traceability Coverage in Open-Source Software`
- CoDoc, Neo4j, source–issue/test/API trace links, JavaParser AST, Symbol Solver, CSV link set, cosine similarity, LLM yes/no 판정, revision history, code clone을 정리했다.
- 사용자 파트로 `알고리즘 2 자바파서 내파트`가 적혀 있고 Elasticsearch Java의 source/test link CSV와 여러 분석용 CSV·노트북 흐름을 정리했다.
- 연구 참여와 데이터 구조 이해의 증거는 되지만, 논문 작성·통계 분석·직접 구현을 증명하지는 않는다.
