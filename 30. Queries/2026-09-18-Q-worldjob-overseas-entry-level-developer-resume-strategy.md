# 월드잡 해외 신입 개발자 이력서 전략

## 결론

김규태의 장기 선호는 미국 → 캐나다 → 유럽이지만, 학부 졸업 직후의 실제 진입 가능성은 `캐나다 IEC → 미국 J-1/WEST → 독일 기회카드·직접 지원` 순으로 보는 편이 현실적이다. 미국 정규 신입 직행은 현지 학위·OPT나 고용주의 비자 지원 없이 가장 어렵다. 따라서 월드잡 이력서는 국가에 대한 열망보다 다음 네 가지를 증명해야 한다.

1. 지원 가능한 체류·취업 경로를 알고 있으며 입사 가능 시점이 명확함
2. 신입이어도 바로 확인할 수 있는 프로젝트와 문제해결 증거가 있음
3. 생활영어가 아니라 개발 업무에서 판단을 설명할 준비를 하고 있음
4. AI가 도운 부분과 본인이 판단·검증한 부분을 구분함

## 2026-09-18 확정 입력

- 졸업예정: 2027년 8월
- 영어: TOEIC 730점 사용자 자기보고. 시험일과 유효기간은 미확인
- 출국 가능 시점: 졸업 후 언제든 가능
- 지원 가능 직무: 백엔드, QA, 데이터
- 해외 경험: TMU 4주·100시간 영어 몰입 과정과 베트남 1개월 AI 프로그램 참여
- 베트남 프로그램 산출물: GraphRAG 팀 프로젝트. 프로그램명·정확한 기간·데이터셋·기술 스택·본인 구현 범위·발표 언어·정량 결과는 추가 확인 필요

직무는 세 개를 동등하게 나열하지 않는다. 상위 포지셔닝은 `신뢰할 수 있는 데이터 시스템을 만드는 신입 소프트웨어 엔지니어`로 두고, 지원 공고에 따라 다음 버전으로 번역한다.

- Backend: API·DB·동시성·정합성·성능
- QA Automation: 테스트 설계·재현·CI·결함 보고·회귀 검증
- Data: SQL·데이터 정제·검색 품질·GraphRAG 평가

### 1. 비자 상태 20점

- 4점: 2027년 8월 졸업예정일과 졸업 후 즉시 출국 가능 상태를 문서화
- 4점: 미국 J-1/WEST, 캐나다 IEC, 독일 경로 중 실제 지원 순서를 확정
- 4점: 여권, 영문 재학·졸업예정증명, 영문 성적표, 자금·보험 관련 서류 체크리스트 완료
- 4점: 2027년 모집 일정에 맞춘 실제 프로필·지원서 제출 또는 고용주 제안 확보
- 4점: 이력서에 과장 없는 work authorization 문장 기재

현재 권장 순서는 `캐나다 IEC 실행 1순위`, `미국 J-1/WEST 도전 1순위`, `독일 백업`이다. 희망국과 실행경로를 분리해 미국의 목표 가치를 낮추지 않으면서 비자 공백을 줄인다.

### 2. 포트폴리오 20점

- 4점: `gyutaetae.github.io`를 모바일·데스크톱에서 정상 접속 가능하게 유지하고 영문 첫 화면 완성
- 4점: Backend, QA Automation, Data/GraphRAG에 대응하는 사례 3개 배치
- 4점: 각 사례에 GitHub, 실행 방법, 테스트 결과, 화면 또는 2분 데모 연결
- 4점: `My Decisions / My Implementation / AI Assistance / Verification / Limitations` 구분
- 4점: 미국·캐나다·유럽 공고 키워드에 따라 첫 프로젝트와 summary를 교체

GitHub Pages 저장소와 프로젝트 문서화 규칙은 존재하지만, 현재 공개 프로필에서 즉시 확인되는 대표 저장소는 `threads-agentic-editor-workflow`, `cuee` 중심이다. 영문 채용 포트폴리오로서 세 직무를 검증하는 대표 사례 재배치가 필요하다.

### 3. 실무 적용 설명 20점

대표 프로젝트는 세 개를 새로 벌이지 않고 하나의 중심 시스템과 두 개의 보조 증거로 묶는다.

1. `Reliable Transaction System` — Java·Spring·PostgreSQL 기반 주문 또는 계좌이체 API. Backend 핵심 증거
2. `Reliability Test Suite` — 같은 시스템의 unit/integration/concurrency/load test, CI, bug report. QA 핵심 증거
3. `Vietnam GraphRAG Project` — 데이터 준비, retrieval 구조, baseline 비교, 검색 품질 평가, 협업 회고. Data/AI 핵심 증거

각 프로젝트 설명은 `Problem → Constraints → Decision → My Work → Verification → Result → Work Application` 일곱 칸을 모두 채운다. GraphRAG는 단순 참가 경험이 아니라 vector RAG 대비 평가 데이터와 본인 기여를 확인할 수 있어야 20점에 기여한다.

### 4. 직무 영어 20점

TMU와 베트남 경험을 역할이 다른 두 증거로 사용한다.

- TMU: 영어 환경 적응, 먼저 질문하고 말하는 자신감, 100시간 과정·A-·출석률 93.75%
- 베트남 AI 프로그램: 해외 기술 프로그램 적응, GraphRAG 팀 프로젝트, 참여가 낮은 팀원에게 피드백을 주며 생긴 갈등과 존중하는 커뮤니케이션 학습

베트남 경험을 `영어로 다국적 협업했다`고 쓰려면 팀 국적과 실제 사용 언어를 확인해야 한다. 현재는 `해외 AI 프로그램의 기술 프로젝트와 협업 경험`까지만 안전하다.

20점 산출물:

- 영문 자기소개 60초와 직무별 지원동기 30초
- CUEE, Java 시스템, GraphRAG STAR 답변 각 1개 이상
- Java 시스템 architecture와 GraphRAG retrieval/evaluation을 영어로 3분 설명한 녹화
- 대표 프로젝트 영어 README 3개
- 영어 모의면접 3회, 피드백·수정 전후 전사 기록

TOEIC 730은 지원 자격의 보조 신호로만 쓰고, 직무 영어 점수는 공개 산출물과 말하기 검증으로 올린다.

### 5. 네트워크·추천 20점

- 4점: LinkedIn headline, About, Featured, Experience, Skills를 영어로 완성
- 4점: 미국 15개, 캐나다 10개, 독일·유럽 5개 등 목표기업 30개와 채용·비자 조건 표 작성
- 4점: 월 2회 이상 잡페어·KOTRA·월드잡·학교·개발자 행사 참가, 질문과 후속 연락 기록
- 4점: 주 3명씩 동문·현직자에게 구체적인 질문을 보내고 월 2회의 정보 인터뷰 확보
- 4점: 지원 전 관계가 형성된 현직자에게 포트폴리오 피드백 또는 referral 가능 여부를 예의 있게 요청

추천은 처음 연락한 사람에게 바로 부탁하지 않는다. `공개 활동 확인 → 구체적 질문 → 조언 반영 → 결과 공유 → 지원 시 피드백·추천 문의` 순서로 관계를 만든다.

## 국가별 현실적인 진입 경로

### 미국

- BridgeUSA J-1 Intern은 해외 대학 재학생 또는 프로그램 시작 전 졸업 12개월 이내인 최근 졸업생을 대상으로 한다.
- 한국인 대상 WEST는 영어교육, 전공 관련 인턴, 여행을 결합한 J-1 Intern 경로이며 최근 졸업생의 12개월 창구가 중요하다.
- 일반 정규직 H-1B는 고용주 지원과 수량 제한·선발 절차가 필요하므로 한국 학부 졸업 직후의 첫 진입 경로로만 가정하면 위험하다.
- 따라서 졸업예정일이 확정되는 즉시 J-1/WEST 지원 가능 기간과 소프트웨어 직무 배치를 확인해야 한다.

### 캐나다

### 유럽

- 독일 기회카드는 인정 학위가 있거나 점수 요건을 충족한 제3국 인재에게 최대 12개월의 구직 체류를 제공한다. 2026년 재정 증명 기준은 월 순액 1,091유로이며 주 20시간 부업과 고용주별 최대 2주 시험근무가 가능하다.

월드잡 FAQ에 따르면 이력서는 최대 30개까지 관리할 수 있지만 공개 이력서는 한 개뿐이며, 지원 시점의 기본 공개 이력서가 기업에 전달된다. 희망 국가·직종은 인재검색에 활용되므로 신중히 선택하되 기업에는 공개되지 않는다.

권장 운영은 다음과 같다.

- 공개 기본본: 국가 중립형 `Entry-Level Backend / Software Engineer` 이력서
- 지원본 A: 미국 J-1/WEST용 — 졸업일, 전공 연관성, 영어 몰입, 인턴으로 배울 목표를 전면에 둠
