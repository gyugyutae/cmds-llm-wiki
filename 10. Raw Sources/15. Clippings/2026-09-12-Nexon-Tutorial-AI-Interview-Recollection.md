이거 방금보고왔는데 리마인드 해서 문제 어떤거 나왔는지 알려주고 어떤식으로 짆애되는지 알려줄게 총 6문제 나왔고 계속해서 꼬리질문계속해서 최대 3개씩하는 거였고 이거 기록하는거는 나중에 취업준비와 내가 모르는것들 공부하기위해서 기록하는거야 내 답변들평가해주고 어떻게 답변하는게 더좋았을지 그리고 이제 앞으로는 어떤부분을 더 보완해서 어떤식으로 답변해야할지 어디서부터 이제 공부해야할지 이거 위키에 잘추가해줘 

1. 어떤것에서 게임에서 흥미를 느꼈나? 
-실시간으로 유저와 메이플스토리에서 메소와 아이템을 교환하는것에 흥미를느꼈다. 실시간으로해서 정말 그안에서 세상이있는것같았고 오래머물고싶었다. 
- 꼬리1. 그것을 하기위해서 어떤 기능을 사용할것인가? 
- tcp 를 사용해서 교환을해야한다. tcp는 유저와 클라이언트 사이 프로토콜으로 신뢰성과 순서를 보장한다. 속도는 느릴수있지만 이것을해야 정확한 교환이 가능하다.  
2. 힙과 스택의 차이점과 생존범위와 어떻게 할당하는지 
- 메모리의 구성요소 데이터 코드 힙 스택이있다. 힙은 위에서 아래로 내려오고  스택은 아래에서 위로 쌓인다 스택은 지역변수와 매개변수를 저장하는곳으로 생존범위는 함수스콥이 끝나면 종료되게된다 힙은 동적으로 프로그래머가 명시적으로 할당한다. 
- 꼬리1. 스택에서 오버플로우가 발생하는 예시 ? 
- 사용자가 스택이 넘치게 푸쉬를 하거나 스택주소를 벗어난거리를 참조하거나 접근하려할때 오버플로우가 발생할수있다. 
3. c++ stl 과 c#의 뭐뭐였는데 이거 두개차이점 
- 나는 c++ c# 잘모른다. 공식기술문서를 참고해서 공부하겠다. 간단한예제코드로 내가지금 가진 파이썬이랑 c언어랑 알고리즘 csㄱ지식기반위에서 빠르게 학습하겠다. 
-이러고 꼬리질문없이 바로끝남 
4. 유저가 때리는거랑 몬스터 종류에 따라서 처리해야하는데 몬스터때릴때마다 로직을 계속해서 이프문으로 늘리면 어떤문제가 있고 그거를 해결하기위해서 어떻게해야하나
- 이프문 많이 하면 사용자가 때릴때마다 계속해서  조건문 탐색해야하기에 시간복잡도 증가하고 개발자가 코드파악하기 힘들고 라인수가 많이 늘어난다. 그래서 별도의 리스트를 만들어서 그곳에서 상성에 따라서 세개의 more_damage,neutral,less_damage 이렇게 세개를 나눠서 관리할것같다. 
- 꼬리1. 이렇게 했을때 유저가 때리는거랑 몬스터 종류랑 매핑할것인가 어떻게 탐색해서 몬스터에게 데미지를 적용할것인가
- 딕셔너리로 해서 유저가 때리는 타입을 키 몬스터타입을 밸류로 해서 매핑할것이다. 
-꼬리2. 만약 몬스터 종류가 계속추가될때 기존코드에서 어떤것들을 추가해야할것인가? 
- 몬스터 계속추가되면 몬스터 타입에 따라서 분류를 하고 기존코드에서 상성에맞는 데미지를 구하는공식들을 추가해야한다. 
- 꼬리3. 이것들을 어떻게 추가할것인가? 
- 데미지를 구하는공식을 별도의 함수로 둬서 다른곳에서도 재사용할수있게할것이고 몬스터 타입을 리스트로 만들어서 별로도 관리할것이다.  
5.만약 맵에 몬스터가 여러개떠있으면 어떤 자료구조로 이거목록을 나타낼것인가 
- 게임의 실시간성이 중요하기에 딕셔너리로 해서 키를 몬스터이름 밸류를 몬스터의 개수로할것이다. 
-꼬리1. 몬스터 계속잡아서 없어지면 어떻게 구현할건가? 
- 몬스터 개수가 1보다 클때는 딕셔너리의 값을 1씩줄이고 1일대 죽이면 0이되므로 딕셔너리에서 팝을해서 없앤다. 그리고 새로운 몬스터가 추가되면 add를 통해서 추가한다. 
-꼬리2. 몬스터 이거 계속해서 갱신하려면 어떻게 구현할건가 ?
- 잘모른다. 근데이거 시간복잡도 측면에서 실시간성을 보장하기위해 빠르게 할수있는것으로 하겠다. 
6. 2D평면상에 n개의 점들이있을때 가장가까운 점을 어떻게 찾을것인가 
- 코사인거리로 할것같다. 
- 꼬리1. 코사인거리로 한다는거 자세히알려달라
- 두개의 변과 한개의 끼인각으로 하면 알수있다. 
- 꼬리2. 그때의 시간복잡도는? 어떤방식으로 탐색해야 빠르게 가장ㄱ가까운것을 알수있나? 
- 딕셔너리로 하거나 아니면 이분탐색으로 가장가까운것을 찾을수있다.
- 꼬리3. 이거 그거 시뮬레이션 탐색? 그런거할때 어떻게해야 가장 효율적으로 할수잇을까? 
-모르겠다.  

- 총평 코딩테스트를 안본다고했지만 실무에서 어떤자료구를 쓰고 어떻게 구현할지 그리고 c++ c# 에 관한 질문들이 많았다. 개인화된 질문은 잘안하는것같고 모두 다 같은 질문을하는것같고 내가 답변하는거에 따라서 꼬리질문이 바뀌고 계속해서 파고들어서 어디까지 아는지 물어본다. C++ C# 에 대한 깊은 이해를 요구하고 시뮬레이션이나 자료구조 알고리즘 시간복잡도 네트워크 측면에서 보완이 많이 필요할것같다. 질문을하고 5분가량 대답할시간을 준다. 나는 한 40분안쪽으로 끝냈다.
