# 큐(CUEE) 65세 이상 사용성 테스트 계획

## 검증 질문

코레일톡 설치·회원가입·자동 로그인을 마친 65세 이상 사용자가 큐의 안내를 받으면 타인의 도움 없이 결제 직전까지 도달할 수 있는가?

## 참여자와 성공 기준

- 참여자: 65세 이상 Android 사용자 5명
- 사전 조건: 코레일톡 설치·자동 로그인 완료, 기본 터치 가능
- 성공: 본인 휴대전화에서 출발지·도착지를 말한 뒤 타인의 도움 없이 결제 직전 화면 도달
- 초기 목표: 5명 중 4명 이상 성공
- 안전 범위: 실제 결제·발권은 진행하지 않음

## 비교 방법

참여자에게 난이도가 비슷한 두 예매 과업을 제시한다. 한 과업은 큐 없이, 다른 과업은 큐와 함께 수행한다. 학습 효과를 줄이기 위해 참여자별 사용 순서를 번갈아 배정하고 출발·도착 조건은 서로 다른 노선으로 구성한다.

## 기록할 지표

| 지표 | 기록 방법 |
|---|---|
| 과업 성공 여부 | 결제 직전 도달 여부 |
| 소요 시간 | 시작부터 중단 또는 결제 직전까지 초 단위 측정 |
| 도움 요청 횟수 | 관찰자에게 질문한 횟수 |
| 중단 단계 | 출발역·도착역·날짜·인원·열차조회·열차선택 중 기록 |
| 안내 오류 | 잘못 강조·미인식·예상 밖 화면을 사건별 기록 |
| 사용 만족도 | 종료 후 5점 척도와 한 문장 이유 |

## 개인정보 원칙

화면·음성·승차권·결제 정보는 수집하지 않는다. 관찰표에는 익명 참여자 번호, 연령대, 성공 여부, 시간, 도움 횟수와 오류 단계만 기록한다.

## 결과 사용

결과는 코레일 무료 실증 제안서에 포함한다. 5명 표본은 시장 전체의 효과를 입증하는 통계가 아니라 다음 개발 우선순위와 실증 가능성을 확인하는 탐색 결과로만 해석한다.
