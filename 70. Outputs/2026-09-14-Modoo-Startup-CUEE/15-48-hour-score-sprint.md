# 모두의 창업 제출 전 48시간 점수 상승안

## 현재 내부 평가

| 축 | 현재 | 제출 전 현실적 상한 | 만점에 필요한 외부 증거 |
|---|---:|---:|---|
| 성장성 | 27/40 | 31/40 | 65세 이상 다수의 사용 결과, 반복 유입, 코레일 실증 회신 또는 제휴 의향 |
| 우수성 | 36/40 | 39/40 | 실제 코레일톡 연속 시연, 여러 노선·표현·기기에서의 재현 결과 |
| 성실성 | 19/20 | 20/20 | 1차 피드백·수상 원본·현재 실행 결과의 전후 증빙 |

점수는 공식 채점이 아니라 준비 우선순위를 정하기 위한 내부 기준이다.

## 9월 15일: 증거 확보

1. 로그인된 코레일톡에서 30~60초 연속 시연을 촬영한다.
2. 영상에는 `큐 버튼 → 음성 명령 → 다음 위치 강조 → 사용자 직접 클릭 → 결제 직전 종료`가 끊김 없이 보여야 한다.
3. Play Console의 앱명·버전·검토 상태·날짜가 보이는 화면을 저장한다.
4. 가능하면 65세 이상 사용자 1명에게 10~15분 관찰 테스트를 진행한다. 성공 여부, 시간, 도움 요청 수, 막힌 단계, 한 문장 반응만 익명 기록한다.
5. 수상 3건의 상장 원본을 한 화면에 정리한다.
6. Play 접근성 서비스 선언과 실제 목표 고객을 일치시킨다. `65세 이상`만을 주 대상으로 설명하면서 근거 없이 `인지·학습 장애 지원`을 선택하지 않는다.

## 9월 16일: 제출 자료 결합

1. 사용자 관찰 결과가 있으면 Q4-1에 `탐색적 1명 결과`라고 표본 한계를 함께 적는다.
2. 실제 시연 영상을 공개 또는 링크 열람 가능 상태로 올리고 Q5에 연결한다.
3. Q4-1의 Play 화면과 로드맵 이미지를 함께 배치해 `현재 실행 → 다음 검증` 흐름을 만든다.
4. GitHub README와 구현 증거 문서를 현재 제출 빌드와 일치시킨다.
5. 이미지 10장의 작은 글씨와 개인정보를 확인하고, 같은 주장을 반복하는 이미지는 뺀다.

## 9월 17일: 사실 대조 후 제출

1. 사용자 수, 테스터 수, 심사 상태와 테스트 통과 수를 제출 시점 기준으로 다시 확인한다.
2. `완료`, `검토 중`, `목표`, `가설` 표현을 구분한다.
3. 링크를 로그아웃 상태나 시크릿 창에서 열어본다.
4. 마감 전에 최종 제출 화면을 저장한다.

## 성장성 만점으로 가는 선정 후 증거 사다리

1. 65세 이상 5명 중 4명 결제 직전 도달 여부를 관찰한다.
2. 실패 화면과 표현을 반영해 두 번째 빌드를 배포한다.
3. 20명까지 확대해 성공률·소요 시간·도움 요청 수의 전후 차이를 기록한다.
4. 코레일에 무료 실증안을 보내 담당자 회신, 미팅 또는 거절 사유를 확보한다.
5. Play 노출→상세 페이지→설치→권한 설정→첫 과업→결제 직전 도달의 퍼널을 측정한다.
6. 코레일 실증 효과가 확인되면 연간 이용료·기술 사용료를 협의한다.
7. 이커머스는 약관과 거래 귀속 방법을 먼저 확인한 뒤 구매 완료 기반 CPS를 시험한다.

## 우수성 만점으로 가는 선정 후 증거 사다리

1. 고정 `진주→서울` 조건을 출발역·도착역·날짜·시간·인원 변수로 분리한다.
2. 표준어 표현 여러 개와 방언·오인식 사례를 테스트 세트로 만든다.
3. 예상하지 못한 화면에서는 잘못 누르게 하지 않고 즉시 멈추는 안전 규칙을 검증한다.
4. 코레일톡 화면 변경과 기기 크기 차이에 대한 회귀 시험을 자동화한다.
5. 실제 사용자 과업과 코드 테스트를 분리해 각각 효과와 안정성 증거로 제시한다.

## Play 접근성 정책 확인

현재 소스는 `isAccessibilityTool=true`를 선언한다. Google Play 정책상 이 선언은 장애인을 돕는 것이 주 목적인 앱에 해당하며, 고령자용 일반 보조 도구라는 설명만으로 자동 충족되지 않는다. 인지·학습 장애 지원을 핵심 목표로 유지하려면 해당 사용자의 구체적인 문제를 조사하고 스토어 설명·선언·실제 기능을 일치시켜야 한다. 현재 확보한 대상자 연구가 없다면 접근성 도구가 아닌 앱으로 선언하고, 앱 안에서 접근성 API 사용 목적·접근 데이터·사용 방식과 동의·거부 흐름을 명확히 보여주는 방향을 검토한다.

어느 방향이든 Play 심사용 영상에는 앱 실행, 전체 공개문, 동의와 거부 흐름, 접근성 설정, 실제 핵심 기능을 포함한다. 모두의 창업 45초 소개 영상과 Play 정책 소명 영상은 목적이 다르므로 별도로 만든다.

## 과장하면 오히려 감점되는 표현

- 사용자 0명 상태에서 `구매전환율이 상승했다`, `사용성이 검증됐다`라고 쓰지 않는다.
- 고정 데모 상태에서 `전국 어디든 자유롭게 예매한다`, `방언도 이해한다`라고 쓰지 않는다.
- Play 검토 중 상태를 `출시 완료`라고 쓰지 않는다.
- 단위 테스트 통과를 고령자 과업 성공 증거로 바꾸지 않는다.
- 코레일 접촉 전 상태를 `제휴 예정`이나 `협의 중`이라고 쓰지 않는다.
