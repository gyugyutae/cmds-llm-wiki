# 큐(CUEE) 코레일 무료 실증 제안서 초안

## 제안 목적

코레일톡 예매 중 다음 행동을 찾지 못해 역 창구를 방문하는 65세 이상 고객이 큐의 음성·화면 안내를 통해 모바일 예매를 직접 이어갈 수 있는지 확인한다.

## 솔루션

큐는 로그인된 코레일톡 위에서 사용자가 도움 버튼을 누르고 목적을 말하면 다음에 직접 눌러야 할 한 곳을 강조한다. 나머지 영역은 흐리게 가리고 쉬운 음성으로 설명한다. 사용자가 모든 버튼을 직접 누르며 결제 직전에서 안내를 끝낸다.

## 현재 단계

- 진주역→서울역 고정 시나리오의 Android MVP
- 실제 코레일톡에서 경로·날짜·열차 선택 흐름 확인
- Google Play 클로즈 테스트 릴리스 검토 중
- 2026년 창업 관련 수상 3건
- 실제 65세 이상 사용자 결과와 코레일 제휴는 아직 없음

## 무료 실증안

- 대상: 코레일톡 설치·자동 로그인을 마친 65세 이상 사용자
- 1차 탐색: 5명, 5명 중 4명 이상 결제 직전 도달 목표
- 후속 실증: 코레일과 규모·장소·기간 협의
- 비교: 큐 사용 전후 과업 성공률, 소요 시간, 도움 요청 횟수와 중단 단계
- 개인정보: 화면·음성·승차권·결제 원문을 개발자 서버에 저장·전송하지 않음

## 코레일에 제시할 가치

1. 고령 고객의 모바일 예매 성공 가능성 향상
2. 역 창구 방문과 단순 사용 문의 감소 가능성 확인
3. 코레일톡 화면을 전면 개편하지 않고 외부 보조 도구로 빠르게 실증
4. 결제와 최종 선택을 사용자에게 남기는 안전한 접근성 지원

## 요청사항

첫 접촉에서는 유료 계약을 요구하지 않는다. 실증 담당 부서 연결, 테스트 범위 협의와 화면 변경 시 안내 안정성을 검토할 기술 창구를 요청한다. 효과가 확인된 뒤 연간 B2B 이용료 또는 기술 사용료를 협의한다.
