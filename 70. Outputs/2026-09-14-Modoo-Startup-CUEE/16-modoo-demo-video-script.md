# CUEE 45초 실제 시연 영상 대본

| 시간 | 화면 | 자막·음성 |
|---|---|---|
| 0~4초 | 로그인된 코레일톡 승차권 예매 홈과 화면 가장자리 큐 버튼 | `코레일톡 예매에서 다음 버튼을 찾기 어려운 사용자를 돕는 큐입니다.` |
| 4~9초 | 큐 버튼을 직접 누름 | `사용자가 도움 버튼을 직접 누릅니다.` |
| 9~14초 | `진주에서 서울 가는 표 예매해줘`라고 말함 | 발화 자막을 그대로 표시 |
| 14~34초 | 다음 위치만 강조되고 나머지는 마스킹됨. 사용자가 각 버튼을 직접 누름 | `큐는 다음에 누를 한 곳을 음성과 화면으로 안내하고, 선택은 사용자가 직접 합니다.` |
| 34~41초 | 열차 선택 후 결제 진입 직전 화면 | `승차권·결제 정보는 저장하지 않으며 결제 직전에서 안내를 멈춥니다.` |
| 41~45초 | CUEE 이름과 한 줄 소개 | `누구나 디지털에서 원하는 일을 스스로 끝낼 수 있도록.` |

## 촬영 확인사항

- 한 번의 연속 촬영을 우선 사용하고 편집은 앞뒤 정리와 개인정보 가림에만 쓴다.
- 실제 코레일톡임을 첫 화면에서 확인할 수 있게 한다.
- 예약번호, 이름, 연락처, 승차권과 결제 정보는 보이지 않게 한다.
- 현재 구현과 같은 명령 및 인원 조건만 사용한다.
- 영상 설명란에는 `진주→서울 고정 데모, 결제 미진행`이라고 적는다.
- 링크는 제출 전에 시크릿 창에서 재생되는지 확인한다.
