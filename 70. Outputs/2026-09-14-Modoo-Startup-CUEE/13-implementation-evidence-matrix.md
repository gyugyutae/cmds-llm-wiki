# 큐(CUEE) 구현·안전·검증 증거표

| 항목 | 현재 확인된 범위 | 증거 | 남은 과제 |
|---|---|---|---|
| 실제 앱 위 안내 | 코레일톡 접근성 노드를 읽고 다음 위치 강조 | 실제 화면 캡처, `CueAccessibilityService` | 최신 코레일톡 전체 E2E 재촬영 |
| 음성 요청 | 큐 버튼을 누른 뒤 Android 음성인식 실행 | 앱 코드·실기기 흐름 | 방언·다양한 말투 데이터 |
| 사용자 선택권 | 역 검색어 외 주요 선택과 탭은 사용자가 직접 수행 | 안전 정책·README·시연 | 65세 이상 사용성 확인 |
| 민감 단계 안전 | 로그인·개인정보·결제 관련 화면에서 중단 | `DefaultSafetyPolicy` 단위 테스트 | 실제 결제 진입 화면 재검증 |
| 개인정보 | 화면·음성 원문 미저장, 사용 결과는 기기 내 최대 200건 | 앱 내 고지·개인정보 처리방침 | Play Data Safety와 문구 일치 확인 |
| Play 접근성 정책 | 별도 고지·동의·거부·철회 화면 구현 | `MainActivity`, 신고 초안, 영상 대본 | 65세 이상 목표와 `isAccessibilityTool=true` 선언의 적합성 결정, 실제 소명 영상·Play 승인 |
| 재현 테스트 | 2026-09-15 JVM 단위 테스트 94개 통과, 실패·오류 0건, Android lint·detekt 포함 Gradle 검증 성공 | Gradle 결과·테스트 코드 | 실제 삼성 기기와 Android 버전 확대 |
| 현재 제품 범위 | 진주→서울 고정 명령과 사전 설정 조건 | `DemoBookingPlan`, parser | 전국 노선 입력 베타 |

## 사실 경계

- 현재 제출 AAB와 공개 소스에는 `어른 2명·어린이 1명` 고정 계획이 포함되어 있다.
- `성인 1명·가장 가까운 시간`은 현재 확인한 AAB·소스와 일치하지 않으므로 동기화 전에는 지원서의 구현 성과로 사용하지 않는다.
- 실제 사용자 반응, 65세 이상 과업 성공률, 코레일 비용 절감과 기업 계약은 아직 없다.
- 앱 내부 개인정보처리방침 연락처는 2026-09-15 소스에서 수정했으나 이미 제출한 검토 빌드에는 반영되지 않았을 수 있으므로 다음 AAB에서 확인한다.
