# CUEE 65세 이상 사용자 1명 관찰 기록지

## 시작 전

- 참여자 번호:
- 연령대: 65~69 / 70~79 / 80 이상
- Android 사용 여부: 예 / 아니오
- 코레일톡 설치·로그인 상태: 예 / 아니오
- 평소 기차표 예매 방법: 코레일톡 / 가족 도움 / 역 창구 / 기타
- 큐 사용 경험: 없음

## 과업 안내

`로그인된 코레일톡에서 큐를 이용해 진주에서 서울로 가는 표를 찾아 결제 직전까지 진행해 주세요. 실제 결제는 하지 않습니다.`

관찰자는 기능이 멈추거나 참여자가 직접 도움을 요청하기 전까지 버튼 위치를 알려주지 않는다.

## 종료 후 세 질문

1. 혼자 다시 사용할 수 있을 것 같나요? `예 / 잘 모르겠음 / 아니오`
2. 가장 어려웠던 순간은 어디였나요?
3. 큐가 없었다면 어떻게 예매했을 것 같나요?
