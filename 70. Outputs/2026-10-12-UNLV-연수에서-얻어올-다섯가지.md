# UNLV 연수에서 얻어올 다섯 가지

기간: 2027-01-10~2027-02-27. 장소: 라스베이거스 UNLV. [공식 공고](https://www.gnu.ac.kr/main/na/ntt/selectNttInfo.do?nttSn=8530723&mi=1126).

사용자는 IT공과대학 배정 2명 중 한 명으로 합격했다고 보고했다. 아래 수량은 Codex의 권장 실행 목표이며 공식 이수 요건이 아니다. 아직 완료한 경험으로 사용하지 않는다.

## 1. 영어로 프로젝트를 설명하고 질문에 답하는 경험

- [ ] 출국 전 30초 자기소개와 2분 프로젝트 설명 준비
- [ ] CUEE 또는 직접 설명 가능한 Java 기능 하나를 영어로 시연
- [ ] 실제 받은 질문과 답하지 못한 질문 기록
- [ ] 첫 설명과 마지막 설명을 비교한 대본·회고 보존

완료 기준: 문제·본인 역할·검증·한계를 영어로 설명하고 후속 질문에 답한 기록이 있다. 녹음·영상은 상대와 수업 규칙이 허용할 때만 남긴다.

## 2. 현지 개발자·교수에게 받은 구체적인 피드백

- [ ] 프로젝트와 질문을 미리 준비해 면담 또는 리뷰 요청
- [ ] 가능하면 두 차례 이상의 피드백 확보
- [ ] 피드백 원문과 내 해석을 구분해 기록
- [ ] 기술 조언·제품 의견·채용 조언을 각각 구분

완료 기준: 누가 어떤 작업을 보고 무엇을 지적했는지 기록되어 있다. 직함·경력은 확인된 범위만 사용한다.

## 3. 피드백을 반영한 코드 또는 제품 개선 한 가지

- [ ] 개선 전 문제와 기대 동작 정의
- [ ] 내가 결정한 변경과 AI가 도운 작업 구분
- [ ] 변경 전후를 같은 조건으로 검증
- [ ] 커밋·테스트·시연·한계 기록 보존

완료 기준: 피드백 → 내 판단 → 변경 → 검증 결과를 다른 사람이 따라갈 수 있다. 계획·모의 실험·실제 사용자 검증을 구분한다.

## 4. 이후에도 연락할 수 있는 동료·멘토

- [ ] 함께 과제·프로젝트 또는 리뷰를 해 본 사람과 연결
- [ ] 가능하면 작업을 아는 관계 한두 명 확보
- [ ] 감사와 수정 결과 공유는 본인이 직접 진행
- [ ] 상대가 동의하는 방식으로 후속 연락 유지

완료 기준: 상대가 내 관심과 작업을 알고 다시 대화할 이유가 있다. LinkedIn 연결 수만으로 완료를 판단하지 않으며 추천·리퍼럴을 당연한 대가로 요구하지 않는다.

## 5. 미국에서 공부하고 일하는 환경에 대한 판단

- [ ] 수업 참여·팀 소통·생활비·외로움·일상 적응 기록
- [ ] 현지 개발자의 업무 경험을 듣고 관광 인상과 구분
- [ ] 미국 취업 목표와 국내 경력·대학원 등 경로 비교
- [ ] 귀국 후 6개월 준비 계획 작성

완료 기준: 미국 취업을 원하는 이유, 직접 확인한 점, 아직 모르는 점, 다음 검증 행동이 구분되어 있다. 라스베이거스 연수를 실리콘밸리 근무 경험으로 일반화하지 않는다.
