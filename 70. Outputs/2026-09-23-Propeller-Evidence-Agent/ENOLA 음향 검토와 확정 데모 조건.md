# ENOLA 음향 검토와 확정 데모 조건

검토일: 2026-09-27
상태: 시나리오 채택 완료 / 소음 계산 파일 검증 완료 / 측정 메타데이터 매핑 부분 검증

## 1. 채택한 시나리오

**XOAR 9×7 제작 재료·공법 변경 시제품의 기존 실측을 비교하고, 미측정 조건으로 확대할 수 있는지 검토한다.** 사용자가 ENOLA와 재료 변경 시나리오를 채택했다. 재료의 단독 인과효과가 아니라 제작 방식까지 포함된 시제품 간 관찰 차이를 다룬다.

- 기본 비교: ABS 대 PA12, Resin은 제3의 참고 후보.
- 기본 운전점: 7350RPM, V=0의 정적 시험. 같은 추력을 맞춘 비교는 아님.
- 기본 음향 채널: `mic1`. 물리적 위치 매핑 확인 전에는 임의로 각도 라벨을 붙이지 않는다.
- 후속 요청: “그럼 실측 파일에 없는 8500RPM이나 새 형상에서도 같은 결론인가?”
- 최종 의사결정: 기존 근거 채택 / 추가 해석 승인 / 추가 실측 요청. 실제 제품 출하·안전성 승인 아님.

## 2. 출처와 확인된 측정 조건

[ENOLA 원본](https://zenodo.org/records/20111572), [연구팀 데이터 소개](https://enola.webs.upv.es/blog/2026/prop-database/), [관련 ICAS 2024 논문](https://www.icas.org/icas_archive/icas2024/data/papers/icas2024_0896_paper.pdf), [2025 확장 논문 안내](https://enola.webs.upv.es/publications/).

관련 논문 §2.2–2.4는 FDM/ABS-M30, SLS/Nylon12, SLA/Grey v4를 비교한다. 측정 시설은 100Hz 차단주파수의 무향실이며, 6개 마이크를 허브에서 2m 떨어진 30도 간격으로 배치했다. 힘 센서와 마이크 교정 후 음향 2초·힘 최소 60초를 측정하고 최소 3회 반복했다고 보고한다. 수치 연구에서는 탄성 변형과 거칠기를 별도로 다뤘다. **이는 관련 논문의 프로토콜이며, 공개 CSV 각 파일의 반복 번호·물리 채널·전처리와의 일대일 대응은 미확인**이다. 확장 논문의 본문은 접근 제한으로 확인하지 못했다.

XOAR 폴더 README는 SLA 풍동 측정만 설명하여 현재 재료별 음향 CSV 전체를 설명하지 못한다. T-Motor README에는 2m·각도별 마이크 번호가 있지만, 이를 XOAR에 그대로 적용하지 않는다. `00_Generalnfo.xlsx`는 스프레드시트 전용 런타임이 없어 이번에 읽지 못했다.

## 3. 실제 음향 파일 검사 및 탐색 계산

`BBDD/XOAR/XOAR_9x7/results/acoustics/`의 `XOAR_9x7_{ABS,PA12,Resin}_acoustic_mic1_7350rpm.csv` 세 파일을 완전 추출했다. ZIP CRC32를 검증했고 모두 131072행, 약 2초, 샘플링 약 65536Hz, `index,time[s],pressure[Pa]` 구조다. 비유한값·역전 시각이 없고 시간 간격은 허용 오차 내에서 일정했다. 원본은 수정하지 않았다.

| 파일 재료 | 파일 전체 DC 제거 RMS 기준 dB | 제안 대역 처리 dB |
|---|---:|---:|
| ABS | 69.26 | 68.00 |
| PA12 | 74.59 | 74.20 |
| Resin | 70.56 | 69.90 |

**표는 재계산된 탐색 지표다. 인증된 소음 측정치, dBA, 저자 논문의 OASPL 재현값, 모든 방향의 방사 소음 또는 재료의 우열이 아니다.** 마이크 매핑·유효 대역·교정·반복 측정 대응 확인 전에는 숫자와 경고를 함께 표시한다. 실측 기록상 차이와 통계적 유의성·원인 추론을 구분한다.

### 팀 제안 처리 방법 — 저자 처리법으로 표현하지 않음

1. 동일 RPM·채널·기록 길이 및 단위 검사 후 전체 평균압력을 제거한다.
2. 파일 전체 수준은 `20 log10(RMS(p-mean(p)) / 20µPa)`로 계산한다.
3. 대역 비교는 Welch PSD, Hann window, `nperseg=8192`, `noverlap=4096`, `nfft=8192`, `detrend=False`, `scaling=density`, 평균 결합을 사용한다.
4. 제안 대역은 100–10000Hz다. 이 해상도에서 실제 포함되는 주파수 bin 중심은 약 104–10000Hz이며, `sum(PSD × Δf)` 후 `10 log10(대역 평균제곱압력 / (20µPa)²)`를 계산한다. A 가중·배경소음 보정은 적용하지 않는다. dB 값을 산술합하지 않는다.
5. 이 대역은 무향실 저주파 한계와 시연 목적을 고려한 팀 제안이지 장비 전체 교정 대역 확인을 대신하지 않는다. 시간 구간·대역·창 조건을 후보마다 동일하게 적용하고 보고서에 기록한다.

[SciPy Welch 공식 문서](https://docs.scipy.org/doc/scipy/reference/generated/scipy.signal.welch.html)를 참고했다. 재현 스크립트 `scripts/analyze_enola_acoustics.py`는 원본을 읽기만 한다. 1Pa RMS 정현파의 이론값과 일치하는지, 시간영역 분산과 전체 periodogram 적분이 일치하는지 테스트를 통과했다. 테스트 신호는 계산 검증용이며 실험 증거로 쓰지 않는다.

## 4. 실제 도구 분기와 Fluent 범위

| 사용자 요청 | 에이전트의 실행과 결론 범위 |
|---|---|
| “7350RPM에서 ABS와 PA12를 비교해줘” | SQL 조건 검색 → Python 음향·하중 계산 → 지표별 비교 및 메타데이터 경고. 측정 조건이 미확인인 항목은 최종 우열 판정을 보류 |
| “8500RPM에서도 같은가?” | 해당 재료 실측 목록에는 그 운전점이 없음을 표시. 선택적으로 보간 추정은 실측과 별도 표시. 현재 CFD가 산출할 수 있는 추력·토크만 점검·사람 승인 후 실행 제안 |
| “재료만 바꾸면 Fluent로 소음 차이를 확인해줘” | 강체·동일 형상·동일 표면/운전 조건 모델에서는 재료 라벨만 바꿔 재료 효과를 검증할 수 없다고 설명. 실측 또는 별도 구조/유동·음향 모델 필요 |
| “새 형상에도 같은 결론인가?” | 기존 실측을 새 형상에 직접 대입하지 않음. 승인된 실제 형상/케이스가 있을 때만 범위 내 유동 해석; 없으면 파일 요청. 새 형상 소음 우열은 자동 확정하지 않음 |

Fluent 실행은 **주어진 형상·표면·운전 조건에 대한 공력 해석**이다. 재료별 탄성 변형·거칠기 등이 모델에 반영되지 않았다면 제작 방식 차이의 재현이라고 주장하지 않는다. 관련 연구의 FSI 분석은 이 구분의 중요성을 보여주지만, 우리 MVP에 FSI를 추가하지 않는다. 이 분기는 데모를 위한 억지 실행이 아니라 도구의 답변 가능 범위를 확인하는 과정이다.

## 5. 남은 메타데이터 확인 질문

저자나 데이터 제공팀에게 다음을 문의할 문안을 준비하되 자동 발송하지 않는다.

1. XOAR 파일의 mic1–mic6이 각각 어느 좌표/각도이며 재료 간 배치가 동일한가?
2. 파일이 개별 2초 기록인지, 반복 실험 중 대표 기록인지? 대응하는 반복 ID와 오차는?
3. pressure[Pa]에 적용된 교정·필터·배경소음 처리와 유효 주파수 범위는?
4. `*_AC.csv` 하중 단위·평균 및 반복 결합 방식은? 해당 음향 기록과 운전점이 대응하는가?
5. 파일의 ABS·PA12·Resin을 논문의 FDM·SLS·SLA 공법/시제품 버전과 매핑해도 되는가?

데모 구현은 이 답변을 기다리지 않고 진행할 수 있으나, 미확인 메타데이터를 채워 넣거나 결과를 제품 합격 판단으로 바꾸지는 않는다.
