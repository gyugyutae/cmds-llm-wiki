## Selection Route

`서류접수 → AI면접 → AI활용 역량평가 → 직군면접 → 팀면접 → 입사`

- 2026년 AI면접: 게임 프로그래머 기본기와 공통역량을 AI와 약 50분간 1:1 대화로 평가한다.
- AI면접 합격 시 2026-10-03 AI활용 역량평가로 이어진다.
- 이번 AI면접·AI활용 역량평가는 2026년에 새로 도입됐다. 과거 넥토리얼 면접 후기는 다음 사람 면접 단계의 참고자료이며 동일 전형의 직접 증거가 아니다.

## AI Interview Retrospective Boundary

- 사용자 자기보고 기준 주 질문은 총 6개였고, 답변에 따라 최대 3개의 꼬리질문이 이어졌다.
- 질문당 응답 여유는 약 5분으로 인식했으며 전체 면접은 40분 이내에 종료됐다.
- 개인화된 프로젝트 질문보다 C++·C#, memory, 자료구조 선택, 확장 가능한 로직, simulation·공간 탐색, network를 게임 상황에 적용하는 문제가 중심이었다고 회고했다.
- 이는 한 명의 응시자 기억에 기반한 관찰이며 모든 지원자에게 동일한 문항이 제시됐는지는 확인되지 않았다.
- 실제 문항과 답변 원문·상세 평가는 `90. Private/`에 분리했으며, 비공개 GitHub 저장소에서만 보관한다.

## Evidence Boundary

- **확인된 공식 정보**: 전형 순서, AI면접 방식·일정·환경, 모집 직무 요구사항.
- **사용자 자기보고**: 서류전형 합격.
- **아직 없는 증거**: 합격 통지 원본, AI면접 녹화·공식 채점 결과와 다음 전형 통지.
- 면접 문항은 유출 금지 대상이므로 문항 원문은 `90. Private/`에만 두고, 저장소를 다시 공개하기 전 반드시 제거하거나 별도 보관한다.

## Post-Interview Learning Priority

1. C++ `vector`·`unordered_map`으로 monster entity의 ID·위치·HP·상태를 직접 관리한다.
2. 2D Euclidean distance, nearest-neighbor 전체 탐색, spatial grid를 구현하고 복잡도를 측정한다.
3. 공격 유형과 monster 유형의 조합을 table·Strategy·polymorphism으로 확장하는 차이를 구현한다.
4. stack/heap, object lifetime, RAII와 stack overflow를 작은 C++ 코드로 재현한다.
5. TCP 전달 보장과 거래 transaction·동시성·멱등성의 역할을 분리해 설명한다.
