# 김규태

> [!info] Profile Scope
> 이 페이지는 김규태가 직접 제공한 취업 준비 맥락을 바탕으로 한 owner entity다. 이력서·자기소개서·면접 답변을 만들 때는 아래 정보를 기본 맥락으로 사용한다.

---

## Overview

김규태는 개발자 취업을 준비하는 경상국립대학교 소프트웨어공학과 학부생이자 SEALAB 학부연구생이다. 2026-2학기는 7번째 정규학기이며 MyGNU 학사원장에는 4학년으로 표시된다. 2003년생 남성으로 경남 진주시에 거주한다고 기록했으며, Codex를 활용한 개발과 개인화된 자동화 workflow에 관심이 있다. 이 standalone LLM Wiki는 프로젝트 증거, 학습 자료, 의사결정 기록, 자기 인식 자료를 Raw Sources / Wiki / Queries 구조로 컴파일해 취업 포트폴리오와 면접 자료로 재사용하기 위해 운영된다. 지원 문서에 사용할 때는 학년·거주지·공개 개인정보를 다시 확인한다.

2026-07-23 자기보고 기준으로 가장 큰 강점은 AI 에이전트를 활용해 아이디어를 빠르게 시작하는 실행력이다. 성장과 돈, 인정, 미래 가능성, 재미를 중요한 동기로 두며, 넓은 관심을 한 분야의 깊이로 연결하고 장기 유지보수와 마감 관리 능력을 보완하려 한다. 상세 자기이해는 [[MOC-김규태 Self Knowledge]]에서 관리한다.

## Role Evidence

- 프로젝트별로 사용자가 결정한 문제·방향과 AI가 구현한 부분을 분리한다. 모든 프로젝트에서 설계·성능·개발을 직접 맡았다고 포괄 주장하지 않는다.
- 팀장 역할을 수행했다.
- Codex로 개발하는 방식을 선호하며, 이를 단순 사용이 아니라 개인 개발 흐름과 자동화 workflow에 맞게 구조화하려고 한다.
- AI 의존 개발자가 되고 싶지 않으며, AI를 개발 역량의 대체물이 아니라 증폭기로 활용하는 개발자로 보이고 싶어 한다.
- 백엔드/금융 포지셔닝에서 `financial-order-latency-lab`과 `Graduation-elasticsearch`는 현재 직접 구현 역량보다 한계 인식과 다음 재현 과제를 설명하는 보조 증거로 사용한다.
- `cuee`는 제품 문제 정의와 안전 경계를 보여주는 보조 프로젝트로 쓰되, Android/Kotlin 직접 구현 경험으로 표현하지 않는다.
- 포트폴리오에서는 열정과 성장가능성을 보여주되, 실제 설계 판단·성능 개선·검증 근거를 함께 제시해야 한다.
- Codex 기반 Threads 자동 리서치/업로드 workflow를 만들었고, 2026-05-25부터 매일 한 게시물이 자동 발행되도록 운영했다. 좋아요·댓글·팔로워 유입이 큰 글을 Excel로 비교해 형식을 개선했으며, 2026-08-31 사용자 자기보고 기준 팔로워 650명을 달성했다.
- Threads의 논문 활용 콘텐츠 workflow에서 게시물이 자동 발행된 뒤, 생성형 AI가 참고자료로 제시한 GitHub 링크를 직접 열어 `404 Not Found`가 발생하는 것을 발견했다고 사용자가 보고했다. 사용자는 게시물을 삭제하고 크롤링 과정을 점검한 뒤 AI에 문제를 설명해 workflow를 수정했다고 밝혔다. 다만 2026-09-21 확인 결과 workflow 로그에 기록된 `Leey21/awesome-ai-research-writing` URL은 정상 접속되고 당시 실행 로그에도 README 수집 내용이 남아 있어, 실제 404가 발생한 정확한 URL·화면과 수정 코드는 아직 확인하지 못했다. 활동실적에서는 추가 증빙 전까지 링크 접근 가능성, 자료 존재 여부, 주장과 근거의 일치를 게시 전에 사람이 검증해야 한다는 학습 사례로 제한한다.
- 2026년 `실리콘밸리` 취업동아리 대표로 영어 모의면접, Velog 글 공유, 교수 피드백 조율, 공지, 예산/지원금 관리, 회의록 작성, 책 수요조사를 맡는다.
- 2026년 경상국립대학교 멋쟁이사자처럼 14기 부대표로 7~8명을 대상으로 CRUD·TypeScript·Codex 사용법을 포함한 백엔드 세션을 매주 진행하고 해커톤 준비를 돕는다.
- 2026년 GNU 개척리더스 창업서포터즈 2기로 참여 중이다. 실제 완료 활동과 산출물은 추후 확인하며, UNLV 지원서에서는 교내 창업 학습을 공유할 기존 채널로 활용한다.
- 해커톤에서 팀이 환경 설정보다 핵심 기능 개발에 집중하도록 Next.js/TypeScript/Bun/Hono/Supabase/Drizzle 기반 `GNU_hackathon_templete`를 준비했다.
- 2025-12-28~2026-01-24 베트남 다낭 FPT 국제학생 PBL을 수료했고, 한국인 3명·인도인 1명·베트남인 1명 팀의 팀장으로 금융·반도체 위험 GraphRAG 프로젝트를 리드했다. 문제 정의·설계·프롬프트·생성형 AI 코드 생성·실행과 Docker 공통 개발 환경을 담당했고, 인도인 팀원은 UI를 담당했다.
- 2026학년도 1학기 GNU Buddy로 2026-02-25~06-11 총 44.23시간 활동하며 외국인 유학생의 학교생활·한국문화 적응을 지원했다.
