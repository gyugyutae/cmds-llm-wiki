# 백테스트 과적합과 편향

## Core Idea

좋은 과거 수익률은 전략의 존재를 증명하지 않는다. 데이터 선택, 미래 정보 누수, 반복 탐색, 비현실적인 체결 가정이 결과를 만들었을 수 있으므로 백테스트는 **수익 생성기보다 오류 탐지기**로 다뤄야 한다.

## 주요 실패 모드

| 실패 모드 | 왜곡 | 확인할 것 |
|---|---|---|
| 생존 편향 | 상장폐지·파산 종목이 빠져 성과가 높아짐 | 당시 투자 가능 종목 집합 |
| 룩어헤드 | 거래 시점 이후 공개된 정보가 들어감 | point-in-time timestamp |
| 선택 편향 | 유리한 기간·종목만 남김 | 선정 규칙과 제외 이유 |
| 다중 검정·데이터 마이닝 | 많은 시도 중 우연히 좋은 설정을 선택 | 전체 시도 횟수와 사전 가설 |
| 비용 누락 | 수수료·슬리피지·시장 충격을 무시 | 주문 규모와 체결 모델 |
| 공매도 가능성 누락 | 실제로 빌릴 수 없는 종목을 매도 | borrow availability와 비용 |

## 최소 검증 기록

- 연구 구간과 최종 미사용 구간을 분리한다.
- 시계열 순서를 보존하고 데이터 누수 검사를 남긴다.
- 매개변수 탐색 범위와 실패한 실험도 기록한다.
- 거래 비용과 체결 지연을 보수적으로 넣는다.
- 위기·저유동성·구조 변화 구간을 별도로 본다.
- paper/live 결과가 백테스트와 어긋난 원인을 추적한다.

> [!note] Bias Check
> Counter-argument: 검증 절차를 많이 추가해도 미래 시장의 구조 변화를 제거할 수는 없다.
> Data gap: Bailey 외 연구는 반복 탐색에 따른 backtest overfitting을, SEC 규칙은 hindsight로 최적화된 hypothetical performance의 위험을 뒷받침한다. 다만 이 체크리스트의 모든 항목을 단일 재현 실험으로 검증하지 않았고, 수학적 보정법도 다루지 않는다.
