# 김규태 Motivation and Execution Pattern

## Pattern

김규태가 말하는 가장 큰 장점은 "바르게"가 아니라 문맥상 **빠르게 시작하는 실행력**이다. 만들고 싶은 아이디어가 생기면 AI 에이전트를 이용해 최소 결과물로 구현한다. 다만 처음 생각한 범위까지 만드는 힘과 장기간 유지·관리하는 힘은 구분해야 한다.

## Strong Motivators

1. **성장** — 지식과 커리어가 축적된다는 감각
2. **돈** — 힘든 일을 견디게 하는 강한 보상
3. **인정** — 이성, 교수, 주변 사람이 성공한 모습을 보게 될 장면
4. **가시적 사용자 반응** — 팔로워, 반응, 실제 이용처럼 변화를 확인할 수 있는 지표
5. **재미와 미래 가능성** — 실제 서비스에 관여하고 영향이 확장되는 감각

외부에 보여줄 수 없어도 알고리즘 공부를 계속할 수 있다고 답했기 때문에 동기가 오직 인정에만 의존하는 것은 아니다. 개발자가 되고 싶은 장기 목표와 지식 축적도 독립적인 동기다.

## Strongest Evidence

Threads 에이전트 워크플로에서는 여러 글 형식을 시험하고, 논문 작성 방식의 반응이 좋자 그 형식을 템플릿으로 만들었다. GitHub Actions로 매일 AI의 논문 활용법을 작성하는 흐름을 자동화하고, 사용자 반응을 보며 유지보수했다. 사용자는 2026-05-25부터 매일 한 게시물이 자동 발행되도록 운영했으며, 좋아요·댓글·팔로워 유입이 큰 게시물을 Excel로 옮겨 형식을 개선했다고 보고했다. 2026-08-31 자기보고 기준 팔로워는 650명이다.

이 사례의 강점은 AI가 글을 만들었다는 사실이 아니라 다음 판단을 사용자가 수행했다는 점이다.

- 여러 포맷을 시험함
- 사용자 반응이 좋은 포맷을 선택함
- 반복 가능한 템플릿으로 고정함
- GitHub Actions 자동화로 운영함
- 지표를 보며 계속 수정함

## Knowledge Accumulation Habit

김규태는 유익하다고 판단한 영상·글·문서를 일회성으로 소비하지 않고 LLM Wiki에 기록하는 습관을 만들었다고 설명한다. 수업과 시험 범위를 넘어서 관심 분야를 계속 파고들고, 흩어진 지식 사이의 wikilink와 Graph View를 보며 반복 관심과 숨은 연결을 발견하는 과정을 좋아한다.

이 습관의 핵심은 자료의 양이 아니라 `관심 신호를 보존하고 다음 질문의 출발점으로 재사용하는 것`이다. LLM Wiki를 통해 프로젝트·학습·판단 기록을 축적하여, AI가 사용자 맥락을 이어서 활용하고 사용자 자신도 관심과 성장 방향을 시각적으로 돌아볼 수 있는 개인 지식 시스템을 구축 중이다.

장학금 자기소개서에서는 이를 데이터 분석 경험으로 과장하지 않고, 호기심을 지속 가능한 학습으로 바꾸는 성실성과 성장 가능성의 증거로 사용한다.

## 2024–2026 Learning Method Transition

- 2024~2025년에는 강의를 듣고 교재를 찾아본 뒤, 모르는 내용을 친구나 교수에게 질문하는 학교 중심 학습을 했다.
- 2025년 1학기에는 전공수업 5개를 동시에 들으며 학습 부담이 커졌고 평점이 3.42로 내려갔다.
- 2025년 2학기부터 기존 공부 방식의 한계를 인식하고 AI를 학습에 활용하기 시작했으며 평점은 3.59로 회복했다. 이 시기의 구체적인 AI 사용 방식은 추가 구분이 필요하다.
- 2026년 1학기에는 Gemini Gem에 `정답을 바로 말하지 말고 단계별 힌트를 제공하라`는 역할을 설정했다. 이해할 때까지 연속 질문하고, 본인이 이해한 내용을 다시 설명한 뒤 정확한지 반문하는 방식으로 바꿨다.
- 이 학습법은 시간과 장소에 제약 없이 즉시 피드백을 받는 `24시간 과외선생님` 같은 역할을 했다고 사용자는 설명한다. 22학점을 모두 취득하고 평점 4.10을 기록했다.

성적 향상은 AI만의 인과효과로 단정하지 않고, 전공수업 부담을 경험한 뒤 질문·설명·재검증 중심으로 학습법을 바꾼 과정과 함께 제시한다.

## Risk

인정욕구는 빠른 성과를 만들 수 있지만, 연애 실패처럼 통제할 수 없는 비교 상황에서는 조급함과 집착으로 전환될 수 있다. 또한 반응이 보이지 않는 깊은 학습이나 유지보수에서는 동기가 약해질 가능성이 있다.

## Operating Rule

- 프로젝트마다 `시작`, `완료`, `유지`를 별도 능력으로 평가한다.
- 외부 지표와 함께 학습 시간, 직접 설명 가능성, 유지보수 기록 같은 내부 지표를 둔다.
- 인정받을 장면을 동력으로 쓰되, 그 사람이 보지 않아도 남는 실력을 완료 기준에 포함한다.

> [!note] Bias Check
> Counter-argument: 팔로워 증가에는 콘텐츠 품질 외에도 노출 알고리즘과 시장 타이밍이 영향을 준다.
> Data gap: 계정 분석 화면, 자동화 저장소, Excel 데이터 구조, 형식별 전후 반응, 기간별 팔로워 변화, 사용자의 직접 판단과 AI 작업 비율을 확인해야 한다.
