# 김규태 개발 도메인 영어 성장 계획

## 현재 증거

[[TMU Global Leadership Program]]에서 한 달 동안 영어 환경에서 먼저 말을 걸고 주문·길 묻기·스몰토크를 하는 자신감이 늘었다고 자기보고했다. 영어 수업과 SDG 주제를 학습했고, 한국인 팀원들과 영어 팟캐스트 대본과 발표 방식을 조율했다는 기록이 있다.

사용자는 베트남 1개월 AI 프로그램에서 GraphRAG 팀 프로젝트를 수행했다고 보고했다. 기존 Velog 원문에는 참여가 낮은 팀원에게 직설적으로 피드백해 갈등이 생겼고, 이후 피드백의 목적과 존중하는 전달 방식을 배우려 했다는 회고가 남아 있다. 프로그램명·기간·팀 구성·사용 언어·데이터셋·기술 스택·본인 구현·평가 결과는 아직 확인되지 않았으므로 현재는 해외 기술 프로그램 참여와 협업 회고로만 사용한다.

이 경험은 기술 영어 숙련을 증명하지 않는다. 빠른 원어민 대화, 공식적인 의견 전달, 개발자 간 기술 대화, README·논문·프레임워크 문서 독해는 다음 학습 과제다.

## 증거를 만드는 루프

| 영역 | 주간 활동 | 남길 증거 |
|---|---|---|
| 읽기 | 공식 Java/Spring 문서 한 절 읽기 | 핵심 개념·모르는 표현·적용 코드 |
| 쓰기 | 프로젝트 변경 하나를 영어로 설명 | README 문단, issue 또는 PR 설명 |
| 말하기 | 설계 판단을 2분 동안 영어로 설명 | 녹음, 전사, 수정 전후 표현 |
| 협업 | 영어 질문·답변을 실제 개발 맥락에서 수행 | 질문, 받은 피드백, 반영 결과 |

## 포트폴리오 표현 기준

- `영어 몰입 과정 수료`와 `실무 영어 협업 가능`을 구분한다.
- 100시간, 성적, 출석률은 증빙 가능한 범위에서만 쓴다.
- 목표는 시험 점수 자체보다 요구사항 이해와 기술 판단 전달의 병목을 줄이는 것이다.

> [!note] Bias Check
> Counter-argument: 주간 산출물만으로 실시간 회의·협상 능력까지 검증할 수는 없다.
> Data gap: 영어 기술 면접, 공개 기술 글의 피드백 기록이 아직 없다. 베트남 GraphRAG 프로젝트는 팀 국적·사용 언어·본인 구현·정량 결과를 추가 확인해야 다국적 기술 협업 증거로 승격할 수 있다.
