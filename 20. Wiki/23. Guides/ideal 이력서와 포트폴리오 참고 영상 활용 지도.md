# ideal 이력서와 포트폴리오 참고 영상 활용 지도

## 수집 목적과 범위

2026-10-11 사용자 답변: **현재 ideal 이력서·포트폴리오를 다듬는 참고 기준으로 활용**.

앞선 업로드 36개 중 취업 전략·이력서·포트폴리오·채용 역량과 연결되는 자료는 자기소개 영상의 누락 보완까지 **24개 파일 / 중복 통합 후 22개 영상**이다. 신규 Raw Source 20개를 보존했고 기존 원문 2개는 재사용했다. 원래 Clippings 파일은 그대로 남겨두었다. `00. Inbox/`에는 대기 Markdown이 없었다. 첫 집계(23개/21개/신규19개)는 제목 필터에서 자기소개 영상 1개가 빠졌던 값으로 정정한다.

본문은 로컬 업로드 자막이며 영상 재생·게시일·자막의 원어 정확성은 별도로 검증하지 않았다. 일부 영어 자막·번역 오류를 그대로 보존했고, 영상에 보이는 화면 템플릿은 자막만으로 복원하지 않았다. 발표자의 관찰·자기보고·전망은 일반 채용 통계가 아니다.

## 현재 결정과 참고 조언 구분

넥슨 Clipping은 자막 외 추가 메모를 포함한다. `21:03` 이후의 요약·개인 소개·코드 함수 설명·사용자 평가 전략 질문·프롬프트 템플릿은 영상 발언과 구분해 Raw Source에 경계를 기록했다. 이는 구현 완료·전형 응시 결과가 아니다.

## ideal 문서에 반영할 순서

2026-10-14 최종 점검: [[2026-10-14-Q-financial-portfolio-final-review-and-video-alignment]]. 최근 두 영상의 해결 관점·제약/비용과 예상 환경의 예방 검증은 원고 구조에 반영됐지만 실제 선택·측정·협업·제출본 압축은 남아 있다. 최근 연결: [[2026-10-12-YouTube-개발자 이력서 4단계와 금융 Java 성장 목적]], [[2026-10-12-YouTube-이력서에 문제 해결을 쓸 수가 없어요-예상 환경과 예방]]. 앞의 22개 영상 집계는 2026-10-11 수집 묶음의 역사 기록이다.

1. 기존 [[2026-10-01-Q-ideal-portfolio-submission-draft]]와 [[금융 백엔드 포트폴리오 2쪽 원고]]에서 프로젝트 정보·사례·근거를 추출한다.
2. 이력서는 개인/협업 프로젝트별 약 7줄로 압축하고 본인 역할·기본 구현·대표 문제 해결을 함께 보여준다. 아직 하지 않은 일은 목표 문서에만 남긴다.
3. 5장 포트폴리오는 증거가 가장 강한 문제 해결 경험을 골라 동일한 블록 순서로 편집한다. 프로젝트 수와 상세 사례 수를 혼동하지 않는다.
4. [[거래 원장 실험과 대표 기술 글 계획]]은 개발·학습 길잡이로 유지한다. 완성된 대표 글은 이력서·포트폴리오에 직접 연결한다.
5. 코드·재현·측정이 완료된 부분만 제출 문장으로 바꾸고 실제 PDF의 2장/5장, 줄바꿈, 링크를 확인한다.

이번 작업은 자료 인제스트와 작성 기준 정리다. 기존 목표 프로젝트의 구현 상태를 승격하거나 실제 2장·5장 제출본을 제작하지 않았다.

## 상충하거나 아직 채택하지 않은 조언

- 큰돌의 최신순 배치와 생각등대의 강점 우선 배치는 목적이 다르다. 현재 사용자 프로젝트형 틀 안에서 가장 강한 근거를 빨리 보이게 배치하되 순서는 편집 시 결정한다.
- 사진 필수/선택, 학력의 위·아래 위치, 전화번호 생략은 공통된 채용 규칙이 아니다. 공고·양식과 개인 선택에 맞춘다.
- “모든 것을 쓴다”와 6~8줄 압축을 함께 적용하려면 역할·기본기·강점을 대표 항목으로 묶는다. 모든 구현을 나열하지 않는다.
- Redis·JVM·Kafka·Flutter·AI 큐 구조는 예시다. 새로운 스택을 채우기 위해 현재 Java 원장 프로젝트 범위를 늘리지 않는다.
- “합격률 향상”, “서류 걱정 없음”, 학점 4.0 비교와 기업군별 수상 가치에는 모집단·비교군·공식 기준이 없다. 사용자 경쟁력이나 합격 가능성을 수치로 환산하지 않는다.

> [!note] Bias Check
> Counter-argument: 대부분의 자료가 한 발표자의 유사 조언이라 영상 수가 많아도 독립된 검증이 늘어난 것은 아니다. 실제 지원처의 요구와 본인 프로젝트 증거로 판단한다.
> Data gap: 영상 화면·원어 자막 정확성·채용 효과·실제 PDF 페이지 수는 미검증이다. Nexon 게임 채용 사례와 비개발자 학습 사례를 금융권 신입 기준으로 일반화하지 않는다.
