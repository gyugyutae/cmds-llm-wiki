# 김규태 Career Narrative

## Working Narrative

김규태는 경상국립대학교 소프트웨어공학과 3학년 학부생이자 SEALAB 소속 학부연구생이다. 현실적인 1차 목표는 금융권 Java 백엔드·거래 인프라 직무이며 장기적으로 퀀트/HFT 시스템 개발에 관심이 있다. Java를 새 주언어로 학습하기로 했고, Python은 부하 테스트·분석·자동화에 활용한다.

장기 목표는 대기업 개발자로 성장하는 것이다. 특히 KB국민은행, 네이버, SK하이닉스, 삼성전자처럼 기술과 산업 도메인이 분명한 회사를 진지하게 살펴보고 있다. 더 멀리는 판교, 싱가포르, 미국 실리콘밸리처럼 개발자가 많이 모이고 트렌드의 최전선에 있는 환경에서 일하는 개발자가 되고 싶어 한다.

---

## Core Tension

현재 가장 중요한 자기 인식은 "AI 의존 개발자가 되고 싶지 않다"는 점이다.

김규태는 Codex와 AI 도구를 적극적으로 활용하지만, 이를 자신의 개발 역량을 대체하는 방식이 아니라 개발 역량에 날개를 달아주는 방식으로 설명하고 싶어 한다. 따라서 포트폴리오와 면접에서는 "AI가 만든 결과물"만 보여주는 것이 아니라, 본인이 직접 이해하고 판단하고 검증한 비-AI 역량을 함께 축적해야 한다.

---

## Target Identity

- **Primary identity**: 금융권 Java 백엔드·거래 인프라 개발자 지망생
- **Current role**: 경상국립대학교 소프트웨어공학과 3학년, SEALAB 학부연구생
- **Target domains**: 증권·은행·핀테크·거래소·금융 IT
- **Desired image**: AI를 전 과정에서 활용하되 결과를 이해·설명·수정·검증하고 책임지는 개발자
- **Problem-solving identity**: 현실 문제를 입력·출력·제약으로 추상화하고, 블랙박스 내부를 하위 문제와 의존성으로 분해해 구현·검증하는 개발자
- **Long-term aspiration**: 대기업 개발자, 이후 글로벌 개발 환경으로 확장
- **Growth gap**: AI 비의존 개발 역량, 코딩테스트, 개발 도메인 영어

---

## Interview Positioning

면접에서 바로 사용할 수 있는 초안:

> 저는 AI 사용 자체를 제한하기보다 학습·설계·구현·테스트 전 과정에 활용하려고 합니다. 다만 기존 프로젝트에서는 생성된 코드와 결과를 이해하거나 검증하지 못한 한계가 있었습니다. 앞으로는 AI를 사용하더라도 문제와 완료 기준을 직접 정하고, 결과를 설명·수정·테스트하며 검증 근거를 남기는 개발자가 되려고 합니다.

문제해결 중심 초안:

> 저는 개발자의 핵심을 코드 작성량보다 현실 문제를 컴퓨터가 풀 수 있는 구조로 바꾸는 능력이라고 생각합니다. 먼저 사용자 문제를 입력·출력·제약으로 추상화하고, 블랙박스 내부를 검증 가능한 하위 문제로 분해한 뒤, AI를 포함한 도구로 구현하고 실제 결과를 테스트하는 개발자로 성장하고 있습니다.

금융/백엔드 방향 초안:

> 데이터베이스 수업의 학기말 프로젝트에서 CPU·GPU·disk latency를 금융 관점에서 비교하는 문제를 제시하고 AI로 실험을 진행했습니다. 당시 생성 코드와 결과를 검증하지 못했다는 한계를 확인했습니다. 다음 Java 주문 시스템에서는 AI를 계속 활용하되 주문 상태·테스트·성능 결과를 제가 설명하고 수정하며 검증할 수 있다는 증거를 남기려고 합니다.

## Bias Check

> [!note] Bias Check
> Counter-argument: 아직 목표 직무가 넓고, AI 활용 경험이 많다는 점은 일부 면접관에게 기본기 부족으로 보일 수 있다.
> Data gap: 각 프로젝트의 본인 기여율, AI가 한 작업과 본인이 직접 한 작업의 분리, 코딩테스트 실력, 영어 실력에 대한 객관 증거가 아직 부족하다.
