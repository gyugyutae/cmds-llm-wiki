# 금융권 백엔드 목표 포트폴리오를 역설계하는 법

## 목적과 현재 위치

김규태는 2027년 8월 졸업 후 금융권 백엔드 취업 또는 인턴 선발을 원한다. 사용자는 이상적인 포트폴리오를 목표로 잡고 필요한 작업을 하나씩 수행 중이라고 보고했다. 실제 목표 초안은 제공되지 않았다. 기존 [[financial-lab]]의 계좌 이체·거래원장 방향과 [[김규태 금융 시스템 개발자 취업 로드맵]]을 기준으로 연결한다.

## 역설계 순서

현재 제출 문서 편집 기준(2026-10-11)은 [[이력서는 프로젝트 포트폴리오는 문제 해결로 구성한다]]다. 이력서는 프로젝트 단위로 2장, 포트폴리오는 대표 문제 해결 경험을 중심으로 5장으로 구성한다. 항목은 1~2줄, 이력서의 한 프로젝트는 약 7줄로 압축한다. 기존 포트폴리오 2쪽 초안은 재료로 보존한다.

1. 목표 직무와 지원 가능한 졸업·근무 조건을 정리한다.
2. 공고와 합격 레퍼런스에서 반복되는 문제·역량·증거 형식을 추출한다. 합격 사례는 원인 증명이 아니다.
3. 이상적인 설명을 먼저 기획한다. 모든 문장에 `목표 / 구현 중 / 검증 완료`를 표시한다.
4. 문장마다 필요한 코드, 실패 재현, 결과 자료, 본인 설명과 AI 기여 경계를 대응시킨다.
5. 시간과 현재 기본기에 맞춰 최소 범위를 정하고, 실무자 피드백으로 조정한다.
6. 작은 단위로 구현·검증하고 실제 근거가 생긴 문장만 제출용 포트폴리오로 옮긴다.

## financial-lab에 적용할 증거 지도

아래는 기존 설계에 대한 적용안이며 완료 보고가 아니다. 2026-09-26 기록상 메모리 기반 이체와 예외 테스트가 첫 단계이고 DB·원장·동시성·멱등성은 미구현으로 기록되어 있다. 이번 인제스트에서 코드를 재확인하지 않았다.

| 목표 설명 | 앞으로 필요한 증거 | 완료 판단 |
|---|---|---|
| 이체 실패에도 잔액·원장 정합성 유지 | DB 트랜잭션과 중간 실패 재현 | 출금·입금·원장이 함께 반영되거나 rollback됨 |
| 중복 요청에도 한 번만 처리 | 멱등성 키와 반복 요청 시나리오 | 재요청·경합에서도 중복 거래 없음 |
| 동시 출금의 잔액 규칙 보존 | 경합 재현과 잠금 대안 비교 | 잔액 불변조건과 실패 처리 확인 |
| 성능 개선을 설명 가능 | 환경·부하·반복 횟수·오류율·p99 기록 | 정확성 유지 및 전후 비교 가능 |

결과가 없는 수치와 금융 실서비스 경험은 채워 넣지 않는다. 피드백과 실제 지원 결과로 목표 자체도 수정한다.

> [!note] Bias Check
> Counter-argument: 레퍼런스에 맞춘 과도한 설계는 기본기와 완성을 늦출 수 있다. 작은 구현과 피드백을 병행한다.
> Data gap: 전략 영상 발표자는 11:57~13:27에서 포트폴리오 취업 경험 부재와 결과 검증 필요성을 밝혔다. 100% 성공은 입증되지 않았다.

## 2026-10-11 참고 영상 묶음 연결

[[ideal 이력서와 포트폴리오 참고 영상 활용 지도]]는 현재 ideal 문서를 다듬기 위한 21개 영상의 원문과 적용 위치를 연결한다. 이력서의 프로젝트 요약은 [[이력서 문장은 문제 해결 결과 도메인으로 압축한다]], 포트폴리오 사례는 [[포트폴리오 문제 해결 블록과 그림을 편집하는 법]], 가정·실측은 [[포트폴리오 트래픽 가정과 측정 결과를 구분하는 법]]으로 점검한다.

금융 이체·원장의 기존 목표를 유지하며 예시 기술을 모두 도입하지 않는다. 이체·대사·복구 사례가 실제 코드·실험으로 검증된 뒤 가장 강한 경험을 고르고, [[대표 프로젝트 설명과 피드백으로 지원 문서를 개선한다]]의 설명 검토를 거쳐 제출 문장으로 바꾼다. 이전 자료의 성공률 주장은 아직 검증되지 않았다.

2026-10-07 구체화: [[2026-10-07-Q-representative-article-detailed-plan]]은 이체 원장 개인 프로젝트·협업 후보·대표 글의 선택 이유와 일곱 절의 증거 요구를 연결한다. 협업 주제는 선정 전이며 금융 소재는 필수로 두지 않는다. 기관 계약을 동일하게 둔 비교 실험과 직접 구현·재현·측정 결과가 생긴 뒤 제출 문장을 확정한다. 자격증은 실제 취득한 경우에만 보조 정보에 표시한다.
