# 인출 간격 교차 자기설명을 학습에 적용하는 법

## 영상에서 추출한 다섯 원리

자료를 가리고 기억에서 꺼내는 인출, 여러 날에 나누는 간격, 혼동하기 쉬운 유형을 비교하는 교차, 풀이 이유를 자신의 말로 만드는 자기 설명, 새 개념을 기존 구조에 붙이는 연결을 묶어 운영한다. 이는 제공 영상의 설명을 컴파일한 것이며 인용 논문 원문 검증을 완료하지 않았다.

## Java·Spring 적용안

책을 읽고 예제를 이해한 뒤 자료를 닫고 작은 기능을 직접 작성한다. 막힌 부분만 확인하고 수정한 다음 다시 설명한다. 예를 들어 DTO·도메인·Repository의 책임을 각각 설명하고, 요구사항을 보고 어느 계층에서 판단할지 구별한다. 현재 학습 수준에 맞게 도움을 점진적으로 줄인다.

학습 흔적은 `무엇을 기억했나 → 어디서 막혔나 → 피드백 → 수정 → 다음 재현일`로 남긴다. [[김규태 Java-Spring-AWS 금융 포트폴리오 기초 학습 트랙]]과 [[financial-lab]]의 실제 코드·검증 기록에 연결한다. 이 인제스트는 새 구현 완료를 뜻하지 않는다.

Python 문제 유형별 적용은 [[김규태 Python 코딩테스트 교차 학습 가이드]]에 둔다. 무작위 과목 전환과 구별하며, 수면을 줄이거나 피드백 없이 오류를 반복하는 것은 영상이 말하는 바람직한 어려움에도 부합하지 않는다.

> [!note] Bias Check
> Counter-argument: 영상 조언의 효과는 과제·기존 지식·상황에 따라 다를 수 있다. 직접 시도한 결과와 반례를 함께 기록한다.
> Data gap: 책/논문 원문 및 사용자의 실제 적용 성과는 이번 인제스트에서 검증하지 않았다.
